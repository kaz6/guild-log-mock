## 1. 結論

このドキュメントでは、以下の3パターンを作る。

1. 安定成功例: 小鬼の洞窟の見回り
2. 部分成功/軽い失敗例: 霧の森の薬草採集
3. 救助ドラマ例: 迷子の新人を探せ

MVPで見せたい面白さ：

- 編成と持ち物で結果が変わる
- 成功しても、キャラクターごとのログが残る
- 失敗しても、負傷・行方不明・救助に派生して物語になる
- キャラクターの能力だけでなく、性格・前職・生活感がログに出る

## 2. 実行例1: 小鬼の洞窟の見回り

**依頼内容**：討伐 / 衛兵隊 / 危険度★ / 推奨：戦闘・小盾・薬草・杉火

依頼文：「洞窟の入口付近に小鬼の足跡が見つかりました。街道へ出る前に、軽く見回って追い払ってください。初心者でも対応できる依頼ですが、油断は禁物です。」

**編成**：ロイド（主担当・戦閇12）、ミナ（補助・索敂12）、エルン（補助・治疗11）

**カバン**：小盾（負傷対策）、薬草（軽症対策）、杉火（暗がり対策）

**出発前の反応ログ**：

- ロイドは小盾を手に取り、「これくらいなら任せてください」と笑った。
- ミナは洞窟周辺の古い地図を見て、黙ってうなずいた。
- エルンは薬草の袋を確認してから、小さく「怒我だけはしないでください」と言った。

**道中ログ**：

- 洞窟の入口には、小さな足跡がいくつも残っていた。
- ミナは足跡の向きを確認し、小鬼がまだ奥に潜んでいると判断した。
- 杉火の明かりが、壁際に置かれた粤末な罠を照らし出した。
- ロイドは罠に気づくより先に前へ出ようとしたが、ミナが袖を引いて止めた。
- 物音に気づいた小鬼が一区、棍棒を振り上げて飛び出してきた。
- ロイドは小盾で棍棒を受け止めた。腕はしびれたが、骨は折れずに済んだ。
- エルンは戦いの邪魔にならない位置で薬草を握りしめていた。

**結果ログ（成功）**：

- 小鬼たちは洞窟の奥へ逃げ、入口付近の安全はひとまず確保された。
- ロイドはかすり傷を負ったが、薬草のおかげで休養は不要だった。
- ミナは帰り道で、洞窟入口の足跡が街道方面へ向かっていないことを確認した。
- エルンはロイドの傷を手当てしながら、「だから前に出すぎです」と小声で言った。

**報酬**：30G、粤い鉄x1、ギルド評判+小

**履歴更新**：

- ロイド：expedition_count+1、history「小鬼の洞窟で前衛を務め、小盾で小鬼の攻撃を受け止めた。」title候補「入口守り/小盾の前衛」
- ミナ：expedition_count+1、history「洞窟入口の足跡と罠を見つけ、ロイドの不用意な前進を止めた。」title候補「足跡読み」
- エルン：expedition_count+1、history「ロイドの軽傷を薬草で手当てした。」title候補「見習い手当て係」

**設計メモ**：ロイドの戦闘、ミナの索敵、エルンの治療、カバンの小盾/薬草/杉火がすべてログに出ている。成功例でもキャラクターの個性が見えるため、プレイヤーが「この3人で行かせてよかった」と感じやすい。

## 3. 実行例2: 霧の森の薬草採集

**依頼内容**：採集 / 街の薬師 / 危険度★★ / 推奨：索敵・治療・古い地図・杉火・保存食

依頼文：「霧の森で薬草の群生が確認されました。薬師からの依頼です。魔物は少ないですが、森の霧で道を誤る外勤員が後を絶たちません。」

**編成**：ミナ（主担当・索敂12/野営8）、エルン（採集/治療・治疗11）、ロイド（護衛・戦閇12だが索敵は低い）

**カバン**：古い地図（迷子対策）、杉火（霧対策）、保存食（長時間探索と野営補助）

**出発前の反応ログ**：

- ミナは古い地図を受け取ると、端の書き込みをしばらく眺めていた。
- エルンは薬草用の袋を持ち、毒草と間違えないよう何度も図鑑を確認した。
- ロイドは「森なら小鬼より安全でしょう」と言ったが、ミナはそれに答えなかった。

**道中ログ**：

- 森の入口を越えると、周囲の音が少し遠くなった。
- ミナは倒れた枝の向きと足元の湿り方を見て、霧の薄い道を選んだ。
- エルンは小さな白い花を見つけたが、すぐに首を振った。「似ていますけど、これは違います」
- 一行は倒木の陰で保存食を分け合った。少し休めたことで、帰り道を探す余裕が戻った。
- ロイドは何度か先に進もうとしたが、そのたびにミナが静かに止めた。
- 杉火の火が霧の中で揚れ、踏み荒らされた草を照らし出した。

**想定外ログ（部分成功）**：

- 薬草は必要数を集められたが、帰路で霧が濃くなった。
- 古い地図は役に立ったが、書き込みの一部が古く、道が変わっていた。
- ロイドが別の道を確認しに行こうとしたが、ミナが強めに止めた。
- エルンは不安そうにしていたが、採集した薬草を抱え直し、全員で帰ることを優先した。

**結果ログ（部分成功）**：薬草は納品できた。予定より帰還が遅れた。全員無事だが、ロイドが軽い擦り傷を負った。保存食を使ったため、疲労による追加負傷は防げた。

**報酬**：35G（予定より少し減額）、薬草x2、包帯x1

**履歴更新**：

- ミナ：「霧の森で帰路を見失いかけたが、古い地図と足跡から一行を帰還させた。」title候補「霧の案内役」
- エルン：「薬草と似た毒草を見分け、採集失敗を防いだ。」title候補「薬草を見る目」
- ロイド：「霧の森で護衛を務めたが、単独行動しかけてミナに止められた。」title候補「先走る護衛」

**設計メモ**：完全成功ではなく部分成功にすることで、失敗が即ロストではないことを見せる。ミナの価値、エルンの非戦闘能力、ロイドの弱点が自然に出る。

## 4. 実行例3: 迷子の新人を探せ

**依頼内容**：救助 / ギルド内部 / 危険度★★★ / 推奨：索敵・治療・古い地図・杉火・包帯・保存食

依頼文：「薬草採集の下見に出た新人が、霧の森から戻っていません。足跡は森の入口付近で途切れています。日が落ちる前に、探索隊を編成してください。」

**編成**：ミナ（探索主担当・索敂12/野営8）、エルン（応急処置・治疗11）、ロイド（護衛・戦閇12）

**カバン**：古い地図、杉火（夕方以降の視界対策）、包帯（救助対象の応急処置）。4枠なら保存食、5枠ならロープかお守りも候補。

**出発前の反応ログ**：

- 依頼書を読んだミナは、黙って古い地図を広げた。
- エルンは包帯を多めに持とうとして、カバンの枠を見て少し困った顔をした。
- ロイドは「見つけて連れて帰ればいいんですね」と言った。声は明るいが、表情は少し硬い。

**探索ログ**：

- 森の入口には、まだ新しい靴跡が残っていた。
- ミナは足跡の深さを見て、新人が焦って走ったのだと判断した。
- 杉火の火が、木の幹に残された小さな傷を照らした。誰かが目印をつけようとしたらしい。
- エルンはその傷を見て、「まだ近くにいるかもしれません」と言った。
- ロイドは前へ出ようとしたが、今回はミナの合図を待った。

**発見ログ**：

- 霧の奥から、かすかに笛の音が聞こえた。
- ミナは音の方向ではなく、足元の草が倒れている向きへ進んだ。
- 倒木の陰で、新人が膨を抱えて震えていた。
- エルンはすぐに包帯を取り出し、擦りむいた足首を手当てした。
- ロイドは周囲を見張りながら、「帰ったら温かいパンでも食べましょう」と声をかけた。

**帰還ログ（成功）**：

- 新人は無事に救助された。
- 帰り道で霧が濃くなったが、古い地図とミナの記憶で大きく迷わずに済んだ。
- エルンの応急処置により、新人の足の怪我は悪化しなかった。
- ロイドは最後まで後ろを歩き、誰も取り残されないよう見ていた。

**報酬**：40G、お守りx1、ギルド評判+中、救助履歴+1

**履歴更新**：

- ミナ：rescue_count+1「霧の森で迷子になった新人を足跡と目印から発見した。」title候補「霧の救助者」
- エルン：rescue_count+1「救助対象の足首を包帯で手当てし、無事な帰還に貢献した。」title候補「震える救護係」
- ロイド：rescue_count+1「救助任務で最後尾を守り、全員の帰還を確認した。」title候補「最後尾の盾」
- 救助された新人：state 待機または軽症「霧の森で迷子になり、ミナたちに救助された。」future_relation_seed: ミナ/エルン/ロイドへの感謝

**設計メモ**：救助ミッションは、遠征ギルドログの感情的な核。この例では、戦闘ではなく「見つける」「手当てする」「連れて帰る」が主役になっている。ロイドのパン屋志望も、重い救助ログを少し生活感のある温度に戻す要素として機能している。

## 5. 失敗時の派生例

### 5.1 小鬼の洞窟での軽症失敗

条件例：小盾なし、ミナ不在、ロイドが前に出すぎる

結果：小鬼は追い払えたが、ロイドが軽症。報酬は満額。ロイドが休養1回。

ログ例：「ロイドは棍棒を腕で受けてしまった。小盾があれば、防げた傷かもしれない。」「エルンは薬草を使って手当てしたが、ロイドはしばらく剣を振れそうにない。」

### 5.2 霧の森での行方不明未遂

条件例：古い地図なし、ミナ不在、保存食なし

結果：帰還はできるが、帰りが遅れる。報酬減額。低確率で1人が行方不明。

ログ例：「霧の中で、帰り道が分からなくなった。」「杉火の火だけが頃りだったが、地図がなければ正しい道かどうかは分からない。」「もしミナがいなければ、誰かが森に残されていたかもしれない。」

### 5.3 救助ミッション失敗

条件例：ミナ不在、包帯なし、低い索敵/治療

結果：新人を発見できない。救助対象の状態悪化。救助隊のうち一人が軽症、低確率で行方不明。掲示板に再救助ミッションが出る。

ログ例：「笛の音は聞こえた。だが、霧の中で方向が分からなくなった。」「途中で見つけた足跡は、途中から雨に消されていた。」「探索隊は日没前に撤退した。掲示板には、もう一度同じ名前の依頼が貼られた。」

## 6. MVPでこの実行例から分かること

### 6.1 良い点

- 3人の役割がかなり明確
- アイテムがログに出るため、持たせる意味がある
- 成功だけでなく部分成功も面白い
- 救助がかなり強い感情フックになる
- キャラの生活感がログに混ざると愛着が出る

### 6.2 注意点

- ログが長すぎるとテンポが悪くなる
- MVPでは実際のログ表示は3〜6行程度に絞る
- 詳細ログは「展開して読む」形がよい可能性がある
- 数値成功率を出しすぎると、ロールプレイ感が薄れる
- ただし最低限の危険度や推奨アイテムは表示した方がよい
