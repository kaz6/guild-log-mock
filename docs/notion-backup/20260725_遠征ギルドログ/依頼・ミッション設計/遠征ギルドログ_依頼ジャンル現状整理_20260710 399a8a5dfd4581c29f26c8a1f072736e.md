# 分析

## 数の薄さ

調査・保全・輸送・救助・護衛・記録は、いずれも1ジャンル1件のみ。質は高い（全て専用生成関数）ので、増やすなら「量」の追加が効く。

## 質の薄さ

quest_herb・quest_signpost（探索）・quest_letter（生活）の3件だけが、まだ最古参の汎用フロー（questEventPools）のままで、専用ハイライトも持たない。数としては生活3件・探索2件と多く見えるが、実際の描写は他ジャンルより薄い。

## 戦闘偏重の懸念

13件中、戦闘は2件のみ。「追い払い」と「討伐」で対比構造もできており、現状は戦闘偏重ではなく、むしろ非戦闘系の比重の方が高い。方針通り保たれている。

## ジャンル別のドラマの重心（現状の実装から観察）

- 生活・輸送・保全: 出発と帰路に重心。不穏さは抑えめ。
- 戦闘・救助: 交戦/発見の判断と結果に重心。結果の早出しを避ける構造。
- 調査・記録: 未解決・判読不能を自然に残す方向。
