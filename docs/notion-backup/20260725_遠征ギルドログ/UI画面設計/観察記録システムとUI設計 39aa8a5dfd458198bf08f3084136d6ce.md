## 指定された結論

現実の自然科学、民俗学、そして医療・福祉現場において「観察記録」とは、単なる事象の羅列ではなく「未知の現象を客観的データの蓄積によって輪郭づけ、既知へと変換するプロセス」そのものである。本調査の結論として、現在企画中のゲーム『遠征ギルドログ』における観察記録システムは、医療記録における「SOAP方式」の論理構造と、統計学・データサイエンスにおける「欠損値メカニズム（MCAR / MAR / MNAR）」の概念を中核に据えることで、これまでにない次元のゲーム体験へと昇華される。

冒険者（一次観察者）がもたらす主観的証言（Subjective）と客観的事実（Objective）の混濁を、ギルド受付嬢やプレイヤー（評価者）がアセスメント（Assessment）し、次なる遠征の推論と計画（Plan）を立てる構造は、現実のフィールドワークにおけるデータ精製の真髄と完全に一致する。さらに、終盤に登場する反ミーム的超常怪異「それ」の表現においては、統計学における「MNAR（欠損データ自体に依存して生じる欠損）」の概念を導入する。「記録がない」こと自体を「そこに何かが存在する」という強烈なメタ情報として逆転させ、空白を埋めるのではなく「空白の形そのものを記録する」ことでラスボスの封印へと至るカタルシスを構築することが、本作の最も重要な設計思想となる。

## 現代の観察記録の基本構造と重要視する考え方

現実の多様な学術・実務分野で用いられる観察記録は、それぞれの目的に応じて構造化されているが、共通して「いつ・どこで・誰が・何を・どのように」という基礎データを、後から客観的に検証可能な形で残すことを至上命題としている。

| 記録の分野と形式 | 基本構造と重視される考え方 | ゲーム『遠征ギルドログ』への応用方針 |
| --- | --- | --- |
| 生物学・野生動物調査 | 日付、場所、天候環境を必須とし、客観的記録と主観的メモを厳格に分離する。写真番号と座標をリンクさせ、行動や痕跡を詳細に記述する。 | 魔物の基本生態データ：冒険者の遭遇日時、天候（霧の日は遭遇率が上昇する等）、残された足跡や食性などの痕跡データに基づくスポーン条件の特定。 |
| 鳥類・自然観察（eBird等） | 観察日時、種名、個体数に加え、歩いたルートと距離を記録する。音声データや大まかな形の特徴を重視する。 | 索敵とルートマッピング：遠征ルートごとの魔物分布図の作成。鳴き声の伝聞から対象の種別を絞り込む同定プロセス。 |
| 生態調査票 | 植物相、動物群集の変化、景観・地形の特徴を網羅的にプロットし、希少性や歴史的自然環境を評価する。 | 環境変化の検知：特定エリアにおける魔物の異常繁殖や、それに伴う植物の枯死といった生態系の異変を示す環境メタデータ。 |
| 行動観察記録（エソグラム） | 動物の行動を細かい単位に分解し、回数・頻度・持続時間を定量的に記録する。 | 魔物の攻撃・行動パターン：冒険者の報告から行動目録を抽出し、弱点や回避戦術を導き出すシステム。 |
| 自然史博物館の標本ラベル | 学名（和名）、採集地（詳細座標）、採集日、採集者（フルネーム）の4項目が不可欠であり、登録番号で厳重に管理される。 | ドロップアイテム管理：誰がどこで持ち帰ったかのメタデータ。これが後に「座標のズレ」や「冒険者の消失」を発見するための決定的な証拠物件となる。 |
| 市民科学（iNaturalist等） | 写真や音声の証拠、地理情報が揃い、コミュニティの複数人が同定に同意して初めて「研究等級（Research Grade）」となる。 | 記録の確度システム：複数の冒険者からの報告（証拠）が一致して初めて、ギルドの図鑑項目が仮称から「確定」へと昇格する仕組み。 |
| 民俗学・人類学ノート | 発話者や話題ごとに区切り、語られた民俗語彙とスケッチ等の図像を直接結びつける。聞き書きによる主観的表現を重視する。 | 怪異の伝承・噂の収集：村人からの依頼文や、冒険者が聞いた噂話。主観や誇張が混じるが、弱点のヒントが隠されている。 |
| 医療・介護（SOAP記録） | S（主観的情報）、O（客観的情報）、A（評価）、P（計画）に情報を分割し、事実と推測の混同を完全に防ぐ。 | 報告書解読システム：プレイヤーが情報を精査し、真実を抽出するためのコアメカニクス。 |

### 観察項目のゲーム内データへの変換

ユーザーが指定した26の観察項目は、現実のフィールドワークにおいて事象の再現性を担保するためのアンカーとして機能する。

- **基礎メタデータ（観察日時、観察者、場所、座標、環境条件、天候、地形）**：事象が発生した舞台装置の定義である。ゲーム内では、特定の魔物が「夜間・雨天・沼地」でのみ活性化するといった出現フラグや、冒険者の疲労度を加速させる環境デバフとして機能する。また、観察者の名前は、後述する市民科学的な「確度」の計算や、終盤の「特定の記録者が世界から消去される」というホラーギミックのトリガーとなる。
- **対象の特定と外形（対象の名称、仮称、分類、個体数、外見的特徴）**：未知の生物に遭遇した際、現実の観察者は仮称や特徴のメモを残し、後日図鑑や専門家の意見と照合する。ゲーム内でも、初回遭遇時は「多脚の獣」「黒い影」といった仮称で記録され、外見的特徴（牙の鋭さ、鱗の色など）の報告が蓄積されることで分類が確定し、正式名称が与えられる。
- **生態的相互作用（行動、痕跡、鳴き声/音、匂い、食性、巣/棲み処、移動経路、他生物との関係、人間への影響）**：エソグラム（動物行動学）の視点が極めて重要となる。単に「怒っていた」ではなく「尾を上下に振り、嘴に土がついていた」といった具体的な動作や痕跡から、造巣中であるといった推測を導き出す。ゲーム内において、これらは魔物の攻撃予備動作の解明、ドロップアイテムの推測、さらには生息域を避けた安全な遠征ルートの構築に直結する。
- **メタ認知と課題（採集物/標本/写真/スケッチ、確度、不明点、推測、次回調査事項）**：物証としての標本やスケッチは、報告の信頼性を担保する。そして最も重要なのが「何がわかっていないか（不明点）」を明記することである。ゲーム内では、この「次回調査事項」がそのままプレイヤーから冒険者へ与える「次回のクエスト目標」へと変換される。

## 事実・推測・未確認情報の分け方

現実の観察記録、とりわけ医療・福祉現場で用いられる「SOAP形式」は、事実と推測を分離するための最も洗練されたフレームワークである。この論理構造を『遠征ギルドログ』の情報処理システムに適用し、プレイヤーが情報の真偽を見極めるゲーム体験を構築する。

### SOAP方式による情報分離の原則とゲームへの変換

**S（Subjective：主観的情報）**：観察者本人から得られた主観的な情報、すなわち「訴え」や「感じたこと」である。記載時はできるだけ本人の言葉をそのまま引用し、推測を入れずにカギ括弧を用いて忠実に書き留めることが求められる。

- 現実の対象：見たこと、聞いたこと、伝聞、矛盾する証言、記録者の主観（恐怖や焦燥）。
- ゲーム内変換（冒険者の報告書）：「背後から巨大な竜に殴られた、絶対にドラゴンだ」「森の奥から女の笑い声が聞こえて寒気がした」。これらは冒険者が体験した「真実」であるが、客観的な「事実」とは限らない。恐怖による誤認や誇張が多分に含まれる一次資料となる。

**O（Objective：客観的情報）**：実際に観察したことや測定によって得られた、誰が見ても同じように判断できる情報である。数字や事実に基づいて淡々と記載し、記録者の解釈（主観）を混入させてはならない。

- 現実の対象：発見した痕跡、測定した数値、採集物、明確な物理現象。
- ゲーム内変換（冒険者の報告書に付随するデータ）：支給したポーションの消費量（5個減少）、防具に付着した酸性の粘液、傷の深さ、帰還に要した日数、座標（X:45, Y:12）。

**A（Assessment：評価）**：収集したSとOの情報を踏まえて、専門職としての評価や分析を行うプロセスである。両者を結びつけ、なぜそのような状況になっているのかを総合的に考察する。

- 現実の対象：観察者の推測、仮説、誤認の可能性の指摘、記録の信頼度の判定。
- ゲーム内変換（受付嬢の注記/プレイヤーの推理）：冒険者は「ドラゴンに殴られた（S）」と主張しているが、打撲ではなく「酸による装備の溶解（O）」が見られる。したがって、ドラゴンではなく巨大なスライム種による不意打ちの可能性が高い。受付嬢が報告書の余白に付箋で「※証言と傷の形状が矛盾しています」とツッコミを入れるUIで表現される。

**P（Plan：計画）**：アセスメントに基づいた今後の支援の方向性や、具体的な対応策である。

- 現実の対象：未確認情報の検証方法、次回調査事項。
- ゲーム内変換（ギルドの観察記録と次回の遠征指示）：推論（A）に基づき、図鑑の「弱点」項目に「仮説：酸性スライム」と記入する。次回の遠征では、対酸性防具を支給し、索敵能力の高いスカウトを編成して真の姿を視認させるという計画（P）を立てる。これが成功すれば、市民科学における「Research Grade」に達し、図鑑の情報が「確定」となる。

## 観察記録のテンプレート化

現実のフィールドノートや標本記録の書式をベースに、『遠征ギルドログ』向けのテンプレートを設計する。生物学的なアプローチと、民俗学的なアプローチの二つを用意する。

### 通常の魔物観察記録テンプレート

```
ギルド公式観察記録：【対象の名称 / 仮称】
■ 登録番号：MON-### ■ 危険度推定：[低・中・高・算定中]
■ 記録確度（Research Grade）：[推測段階 / 複数証言一致 / 標本による確定]

1. 基礎データ
  - 遭遇座標：[X:***, Y:***]（地域名：________）
  - 主な生息環境：[森林・洞窟・水辺など]
  - 初回報告日時：帝国暦__年__月__日
  - 活性化条件：[例：濃霧・夜間]

2. 客観的特徴（Objective Data）
  - 分類体系推定：[獣類・鳥類・無機物など]
  - 外観・サイズ測定値：[メートル表記 / 比較対象]
  - 採集標本・痕跡：[足跡の形状、ドロップ品、爪痕の深さ]

3. 行動観察記録（Ethogram）
  - 攻撃パターン：[例：前肢を2回叩きつけた後、直線的な突進行動に移行する]
  - 生態（食性・巣）：[例：ゴブリンの集落を襲撃する肉食性。南の洞窟に骨が散乱]
  - 特記事項：[鳴き声の周波数、特有の匂い]

4. 評価と対策（Assessment & Plan）
  - 冒険者の証言録（Subjective）：「（冒険者の発言をそのまま引用。感情的表現や擬音語を含む）」
  - ギルド評価：[証言と痕跡から導き出された弱点や生態の推測]
  - 次回検証事項：[例：火属性魔法が有効か否かの実地検証を要求する]
```

### 怪異 / 超常怪異観察記録テンプレート

民俗学やオカルト調査の要素を取り入れ、物理的法則を無視する事象や、主観の混濁、矛盾する証言を許容するフォーマットである。

```
ギルド公式観察記録：【怪異指定：対象の名称 / 仮称】
■ 登録番号：ANO-###（※取り扱い注意） ■ 認識汚染度：[低・中・高・致死]

1. 発生条件と呪術的メタデータ
  - 頻発座標：[X:***, Y:***]付近（地域名：________）
  - 発生のトリガー：[例：特定の童歌を歌う、夜間に振り返る]
  - 民俗伝承（Subjective）：[現地の民俗語彙や昔話の聞き書きの引用]

2. 観測された異常事態（Objective/Anomaly）
  - 物理的影響：[例：周囲の気温が急激に低下、方位磁針の狂い]
  - 証言の矛盾と認識のブレ：
    冒険者A：「赤い服の女が立っていた」
    冒険者B：「巨大な黒い犬に吠えられた」
    ※ギルド評価：対象は定まった形を持たず、視認者の深層心理にあるトラウマを投影している可能性が高い。

3. 防衛・回避プロトコル（Plan）
  - 有効な対抗手段：[物理攻撃無効。特定の護符、塩、視線を合わせない等の行動規律]
  - 未解明の謎：[なぜその土地に執着しているのか、過去に何があったのか]
```

## 「それ」専用の観察記録テンプレート

物語終盤に登場する反ミーム的ラスボス「それ」は、直接見る・知る・説明すること自体が危険な存在である。直接的な記録を残そうとすると、情報密度の高さを嗅ぎつけられ、記録もろとも執筆者が世界から消去される。この現象を表現するために、データサイエンスにおける「欠損値（Missing Data）」の理論を適用する。

欠損値発生のメカニズムには以下の3通りが存在する。

1. **MCAR（Missing Completely At Random：完全にランダムな欠損）**：システムエラーや偶発的な紛失など、欠損の発生が他の変数と全く無関係なもの。
2. **MAR（Missing At Random：観測データに依存する欠損）**：天候が悪い日は視界が悪く記録が欠損するなど、他の観測可能な変数に依存するもの。
3. **MNAR（Missing Not At Random：欠損値自体に依存する欠損）**：データそのものが原因で記録が失われる。

「それ」が引き起こす現象は、この**極端なMNAR**である。その情報を知ってしまったが故に、データが強制的に欠損させられるのだ。

したがって、プレイヤーは「それ」を直接記述するのではなく、**「それ」によって生じたMNAR的な矛盾（座標のズレ、物資の消失、名簿の空白）を蓄積することで、逆説的に「それ」の存在領域（空虚の輪郭）を浮き彫りにしなければならない。**

### 反ミーム的怪異「それ」専用：空虚を記録するテンプレート

```
ギルド公式観察記録：【空虚の輪郭 / █████】
■ 登録番号：NULL-000
■ 警告：本記録に直接的な容姿・名称・生態を記述してはならない。記述された場合、該当文書および執筆者は直ちに[削除済]となる。

1. 観測不能領域の確定（空間的欠落）
  - 座標の消失点（Objective）：
    X:70〜75, Y:40〜45 の領域において、帰還者のマッピング情報が常に欠落している。
    遠征ルート[A村]から[B砦]へ向かう際、計算上の所要時間は3日だが、当該地域を通過した全パーティの食料・水が「5日分」消費されている。
    結論：地図上に存在しない「忘れられし地」が物理空間に折り畳まれて存在している。

2. 認識のズレと名簿の空白（時間的・人的欠落）
  - 矛盾する支給記録と証言（MNARの証明）：
    帝国暦〇年×月、ギルド倉庫から寒冷地用テントが「4張り」持ち出された記録がある。
    しかし、同時期の出撃名簿には、該当パーティの冒険者は「3名」しか登録されていない。
    帰還した3名は「最初から我々は3人だった」と証言している（Subjective）。
    結論：我々は誰か1名を忘却している。情報密度の高い詳細なフィールドノートを書いていたスカウトが「最初からいなかったこと」にされた。

3. 生態の逆説的推論（Assessment）
  - 捕食対象の法則性：情報密度の高いものを好む。人間の脳、詳細な報告書、完成された図鑑など、体系化された知識が狙われる。
  - 忌避するもの（弱点）：欠落した、不完全で「歯抜け」の記録。意味を持たない情報や不確実な推論には興味を示さず、捕食を免れることができる。

4. 封印プロトコル（Plan）
  - 対応策：決して完成された情報を与えてはならない。直接説明することは敗北（消滅）に向かう。
  - 最終目標：この空白の集積によって浮かび上がった「形（欠落）」に対し、かつて世界から消し去られた【真の名前】をギルドマスター（プレイヤー）が名付けること。概念として世界に再定着させることで、「それ」を物理法則の檻へと引きずり下ろし、封印する。
```

## 図書館へ送る観察記録の選択UI案

ストーリー中盤、プレイヤーは王立図書館へこれまでの観察記録を送付する選択を迫られる。このイベントは、プレイヤーに対する「MNAR（意図的な情報の欠落）」のチュートリアルとして機能する。図書館は「情報密度の極めて高い場所」であり、「それ」の最大の標的になり得る。

### UIとシナリオフロー

**前提状況**：完璧な観察記録（詳細な生態や弱点がびっしり書かれた図鑑）を送付した場合、手紙のやり取りが途絶え、後日「王立図書館などという施設は最初からこの国に存在しない」と受付嬢が語るバッドエンドの示唆ルートに入る。正解は、意図的に「歯抜けの、未完成な、矛盾を含んだ観察記録」を3つ選択して送り続けることである。

**UI画面構成**：

- 左ペイン（インベントリ）：これまでに完成させた「美しい観察記録（Research Grade）」と、情報が足りず受付嬢が「ボツ」の付箋を貼った「未完成/欠落のある観察記録」が混在してリストアップされている。
- 右ペイン（送付スロット）：図書館への送付枠が3つ用意されている。

**プレイヤーの選択とフィードバック**：プレイヤーがあえて「未完成の記録（例：討伐したはずなのにドロップ品が一切記載されていない、遭遇座標が白紙、遭遇者の名前がインクの染みで読めない等）」を3つ選んで送付する。

**図書館からの返信（手紙文面案）**：数日後、図書館の司書長から一見すると普通の礼状が届く。しかし、UI上の特殊ギミックにより、司書長が裏のメッセージを伝えていることが判明する。

【表の文面】

```
遠征ギルドマスター 貴下

平素より格別のご高配を賜り、厚く御礼申し上げます。
貴殿の不断の努力によりもたらされた観察記録、確かに拝受いたしました。
王立図書館の蔵書として、後世の知識の礎となることでしょう。
些末ではございますが、調査の報酬を同封いたします。
今後とも変わらぬご協力を賜りますようお願い申し上げます。

王立図書館 司書長
```

**シナリオ的展開**：手紙を読んだ受付嬢が不審そうにプレイヤーに語りかける。「マスター、この手紙……おかしくないですか？ 同封されている報酬リストの中に、『不忘の本』なんてアイテム、どこにも書かれていません。……でも、手紙の入っていた封筒の底に、真っ白な、何も書かれていない分厚い本が入っていたんです。これ、目録に載せ忘れたんでしょうか？ それとも……『意図的に記録しなかった』？」

図書館の司書長は、送られてきた「歯抜けの記録」を見て、「何者かが情報を喰っている」「詳細に書き記すことは危険である」というメタメッセージを即座に理解した。だからこそ、表向きは普通の礼状を装い、記録に残らない形で、対抗手段である「不忘の本」を託したのである。

## 手紙配達依頼の連続失敗から始まる違和感案

ゲーム序盤〜中盤にかけて、プレイヤーに「システム上のエラー」や「乱数による不運」と錯覚させる形で、後に繋がる「忘れられし地」の伏線を張るイベントである。

**イベントの条件と進行**：

1. **簡単な依頼の提示**：「隣の〇〇村へ、村長宛の簡単な手紙を届ける」という、最も難易度の低い依頼がギルドボードに貼り出される。
2. **不可解な連続失敗の発生**：優秀な冒険者を派遣しても、なぜか必ず「失敗」して帰還する。
    - 失敗報告1：「道に迷った。あんな一本道で迷うはずがないのに、気づいたら元の街道に戻っていた」
    - 失敗報告2：「天候が急激に悪化して進めなかった」（しかし、同じ日に同じ座標周辺に向かった別の冒険者は「快晴だった」と報告している）。
    - 失敗報告3：「手紙を落とした。いつ落としたのか、そもそも最初から持っていたのか全く記憶がない」
3. **違和感の可視化（受付嬢のアセスメント）**：同じ依頼が同じ座標（X:72, Y:41周辺）で3回失敗した時点で、受付嬢が報告書の束を睨みながらプレイヤーに話しかける。「マスター、おかしいです。この手紙の宛先……『〇〇村の村長、██さん』ってなっていますけど、私たち、どうしてこの手紙を受理したんでしたっけ？ 依頼人の名前が……ギルドのどの名簿を見ても、どこにも記録されていないんです。それに、冒険者たちが迷ったというこの座標……古い地図には〇〇村があることになっていますが、最新の測量図では『ただの空白の森』になっています。」
4. **伏線の着地**：プレイヤーは、「宛先も、依頼人も、目的地も、最初から存在していなかったのではないか？」という事実に気づく。手紙という「情報」を運ぼうとしたからこそ、「それ」の領域に触れてしまい、システム的に弾き出されていたのである。これが、情報密度の高いものを喰う「忘れられし地」への最初の接触となる。

## 観察記録とゲーム進行の関係

本ゲームにおける観察記録は、単なる「やり込み要素」ではなく、ゲームの進行と攻略をダイナミックに変化させる「メインエンジン」として機能する。

1. **仮説と検証によるルート開拓**：未踏破地域の探索は、まず冒険者が持ち帰る「不完全な噂（S）」から始まる。プレイヤーが記録上の「矛盾」や「謎」を指摘し、次回探索の「計画（P）」として特定のアイテムを持たせたり、特定ルートを指定することで、新たなマップや奥地がアンロックされる。
2. **情報の精度（確度）が生存率に直結**：複数の報告が一致し、観察記録が「Research Grade（確定）」に達することで、冒険者を派遣する際のシミュレーション精度が向上する。弱点が確定していれば自動的に弱点属性の武器が選ばれ、被ダメージが減少し、生還率が劇的に跳ね上がる。
3. **メタ情報の武器化とルールの反転（終盤ギミック）**：通常の魔物には「詳細な情報を集めること」が正解だが、終盤の「それ」の領域に入るとこのルールが完全に反転する。記録が詳細になればなるほど（情報密度が高まるほど）、「それ」のヘイトを買い、派遣した冒険者がロスト（名簿から消滅）する確率が上がる。プレイヤーはあえて「記録を破棄する」「記憶を消すアイテムを持たせる」「白紙の報告書を提出させる」という逆転の発想を強いられる。最終的に、集めた「空白（欠損値）」の輪郭から「真の名前」をタイピング入力等のUIで与え、対象を既知の概念に固定化することで、ゲームクリアとなる。

## 影響、MVP案、次に決めるべきこと

### 影響

本システムを導入することで、プレイヤーは単なる「文字を読むだけの放置ゲーム」の傍観者ではなく、「情報を精査し、真実を導き出すデータサイエンティストであり民俗学者」としての強い没入感を得る。特に「空白を記録する」というゲーム体験は、既存のモンスター図鑑システムに対する痛烈なアンチテーゼとなり、インディーゲーム界隈において極めて高く評価される「反ミーム的（SCP的）ナラティブ体験」を提供できる。

### 最小有効プロダクト（MVP）案

コアメカニクスの面白さを検証するため、まずは以下の要素に絞ってプロトタイプを作成する。

1. **3種類の報告書生成**：「成功した普通の報告」「主観と誇張が混じった報告（S）」「アイテム消費など客観的事実のみの報告（O）」を自動生成するロジック。
2. **アセスメントUI**：プレイヤーが2つの報告書の矛盾点（例：「快晴だ」というS証言と、「泥汚れがついている」というO事実）をクリックで紐付け、「雨が降っていた」という真の天候を導き出すパズルシステム。
3. **1体のミニ怪異**：情報の欠落（MNAR）を体験させるためのチュートリアル怪異（例：遭遇した冒険者のポーションがランダムで1つ、消費記録にも残らず消滅するスライム）。

### 次に決めること

1. **テキスト自動生成とバイアスの仕組み**：冒険者の報告書（Subjectiveな部分）のテキストを、どのようなロジックで生成するか。冒険者の性格（臆病、猪突猛進、虚言癖）による証言バイアスのパターン定義と、それをテキストに反映させるフラグ管理。
2. **UIデザインのトーン＆マナー**：「羊皮紙と羽ペン」という王道のファンタジー路線にするか、SOAP的な管理を強調する「タイプライターとファイルバインダー（官僚的）」にするかの決定。「それ」の異常性を際立たせるには、後者のような規則正しいフォーマットが徐々に崩壊し、黒塗りや文字化けに侵食されていく演出が効果的である。
3. **「それ」に与える真の名前と世界観の構築**：プレイヤーが最後にたどり着き、タイピング入力する「名前」は何なのか。シナリオの根幹となるため、ギルドの創設理由、忘れられし地の歴史、そして「なぜその怪異は情報を喰うようになったのか」というバックストーリーとの深い結びつきを構築する必要がある。
