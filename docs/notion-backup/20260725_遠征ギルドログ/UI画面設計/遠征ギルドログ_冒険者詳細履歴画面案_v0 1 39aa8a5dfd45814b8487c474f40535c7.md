## 1. 結論

冒険者詳細画面は、単なるステータス画面ではなく、プレイヤーが「このキャラをまた送り出したい」「この子の履歴を見返したい」と思うための画面にする。

MVPでは、以下が見えれば十分：名前、職業/性格/前職、状態、能力値、得意なこと、苦手なこと、生活感のある一文、ギャップのある一文、最近の遠征ログ、履歴メモ

## 2. 画面構成案

### 2.1 上部

名前、職業、状態、一言フレーバー

例：ロイド / 戦士 / 待機中「村の衛兵隊にいた若い戦士。お金を稼いだらパン屋を開きたいと思っている。」

### 2.2 中央

能力値：HP、戦闘、索敵、野営、治療、運

得意：討伐、護衛、仲間を庇う

苦手：罠、森、慎重な撤退判断

### 2.3 下部

履歴：遠征回数、救助回数、負傷回数、最近のログ、称号候補、将来: 装備/遺品/思い出の品

## 3. 初期冒険者詳細案

### 3.1 ロイド

**基本プロフィール**：職業 戦士 / 性格 勇敢 / 前職 元兵士 / 状態 待機中

**役割**：前衛担当。小鬼や護衛任務では頼れるが、索敵や罠の発見は苦手。

**性格メモ**：勇敢でまっすぐ。危ないと思うより先に身体が動く。仲間を庇う場面では強いが、前に出すぎて怪我をしやすい。

**得意**：討伐、護衛、仲間を守る行動、小盾を使った防御

**苦手**：霧の森、罠、細かい観察、慎重な撤退判断

**生活感フレーバー**：お金を稼いだらパン屋を開きたいと思っている。休みの日は市場のパン屋をのぞき、焼き加減について店主に質問している。

**ギャップフレーバー**：剣の手入れより、パン生地のこね方の話をしている時の方が目が真剣になる。甘いものにはかなり弱い。

**最近のログ**：

- ロイドは真っ先に小鬼の前へ飛び出した。仲間が止めるより早かった。
- 小盾が棍棒を受け止めた。ロイドは「これくらい大丈夫です」と笑った。

**履歴メモ**：まだ大きな履歴はない。小鬼の洞窟で小盾を構えた姿が、最初の記録として残っている。

**将来フック**：引退後にギルド近くでパン屋を開く／後輩に剣を託す／「パン屋志望の前衛」としてプレイヤーに覚えられる

### 3.2 ミナ

**基本プロフィール**：職業 盗賊 / 性格 慎重 / 前職 元猟師 / 状態 待機中

**役割**：探索担当。足跡、霧、森、帰り道に強い。救助依頼では特に頼れる。

**性格メモ**：慎重で口数は少ない。派手な活躍より、失敗しない道を選ぶ。危険な場所では歩調を落とし、誰かが先走ると無言で止める。

**得意**：索敵、足跡追跡、森歩き、迷子対策、帰路確保

**苦手**：正面戦闘、勢い任せの討伐、感情を言葉で説明すること

**生活感フレーバー**：私服は意外と派手。休みの日は大きな柄のスカーフや鮮やかな上着を着ているが、本人はそれを派手だと思っていない。

**ギャップフレーバー**：無口なのに、服選びだけは迷いがない。森では誰よりも目立たないのに、街では誰よりも目立つ日がある。

**最近のログ**：

- ミナはぬかるみに残った浅い足跡を見つけた。本人は「まだ新しい」とだけ言った。
- 霧が濃くなったところで、ミナは無言で一行の進路を変えた。

**履歴メモ**：霧の森で帰り道を見失いかけた一行を、足跡と地図から連れ戻した記録が残っている。

**将来フック**：救助された新人から強く慕われる／古い地図が思い出の品になる／派手な私服が受付ヒロインや仲間のログで触れられる

### 3.3 エルン

**基本プロフィール**：職業 魔術師 / 性格 臆病 / 前職 元薬草採り / 状態 待機中

**役割**：治療・調査担当。毒草や怪我の手当てに強いが、HPが低く戦闘は苦手。

**性格メモ**：臆病で心配性。出発前に荷物を何度も確認する。だが、傷や毒を前にすると震えながらも的確に動ける。

**得意**：治療、薬草判別、毒対策、救助対象の応急処置

**苦手**：前衛戦闘、長時間の過酷な遠征、急な大声、暗い洞窟の先頭

**生活感フレーバー**：意外にもお酒に強い。宴会では端の席で小さく飲んでいるだけなのに、最後まで平然としている。

**ギャップフレーバー**：普段は小さな物音にも驚くが、酔った冒険者の介抱だけは妙に手慣れている。薬草の話になると、声が少しだけ大きくなる。

**最近のログ**：

- エルンは出発前に、薬草と包帯を三度確認した。それでもまだ足りない気がしているようだった。
- 負傷した新人を前に、エルンの声は震えていた。それでも包帯の巻き方は正確だった。

**履歴メモ**：毒草調査で似た草を見分け、負傷を防いだ記録が残っている。救助任務では包帯を握りしめて出発した。

**将来フック**：誰かの命を救った包帯や薬草袋が記念品になる／苦手な戦闘で一度だけ前に出るイベント／宴会ログや酒場ログでギャップを出せる

### 3.4 汎用新人

**基本プロフィール**：職業 なし/見習い / 性格 普通 / 前職 なし / 状態 待機中

**役割**：平均的な新人。突出した能力はないが、低リスク依頼で経験を積ませやすい。

**性格メモ**：まだ自分の得意分野を見つけていない。先輩の動きをよく見ているが、たまに見すぎて足元がおろそかになる。

**得意**：街道配達、低リスク依頼、先輩同行での経験稼ぎ

**苦手**：高危険度の救助、専門性が必要な毒草調査、単独判断

**生活感フレーバー**：受付に提出する報告書の字だけは妙にきれい。本人は昔から帳簿を写す手伝いをしていたらしい。

**ギャップフレーバー**：まだ冒険者らしい武勇伝はないが、ギルドの備品棚を誰よりもきれいに戻す。緊張すると敬語が過剰になる。

**最近のログ**：

- 新人は依頼書を何度も読み返し、最後に小さくうなずいた。
- 荷物を届け終えると、新人は報告書の端を丁寧にそろえて受付へ出した。

**履歴メモ**：まだ目立った履歴はない。最初の遠征で誰に同行したかが、この新人の今後の色を決めるかもしれない。

**将来フック**：ロイドに同行すると戦闘寄りになる／ミナに同行すると探索寄りになる／エルンに同行すると治療寄りになる／師弟関係の種にできる

## 4. 将来フックの扱い

重要：将来フックは、プレイヤーにそのまま見せない。開発側の裏データ/イベント種として管理する。

プレイヤーには以下のように間接的に見せる：

- 詳細画面では、生活感フレーバーや最近のログとして薄くにじませる
- 条件が揃ったとき、イベントログや履歴更新として表に出す
- 「この子、将来こうなるのかな」とユーザーが自然に想像できる程度にする
- 明確な未来予告にはしない

例：ロイドの「パン屋を開きたい」は詳細画面に出してよい。ただし「将来パン屋になる可能性」は裏データとして持ち、引退時や特定イベント時に初めてログへ反映する。ミナの「古い地図が思い出の品になる可能性」も、詳細画面には出さない。実際に救助回数や使用回数が増えた時に、ログや記念品として発生させる。

## 5. UI上の見せ方

### 5.1 短縮表示

冒険者一覧では、名前、職業、状態、得意タグ2つ、生活感フレーバー1行だけ表示。

例：ロイド / 戦士 / 待機中「得意: 討伐・護衛」「お金を稼いだらパン屋を開きたいと思っている。」

### 5.2 詳細表示

性格メモ、得意/苦手、最近のログ、履歴メモ、ギャップフレーバー

### 5.3 将来表示

装備履歴、受け継いだ装備、救助された/した相手、師弟関係、墓/記念品/遺品

## 6. 設計メモ

この画面は、攻略情報とキャラクター妄想の接点にする。

プレイヤーが見る順番は以下が理想：

1. 能力値を見る
2. 得意/苦手を見る
3. 生活感フレーバーを見る
4. 「この子いいな」と思う
5. 遠征に出す
6. 帰還ログで履歴が増える
7. また詳細画面を見に来る

この循環ができると、遠征ギルドログの愛着部分がかなり強くなる。
