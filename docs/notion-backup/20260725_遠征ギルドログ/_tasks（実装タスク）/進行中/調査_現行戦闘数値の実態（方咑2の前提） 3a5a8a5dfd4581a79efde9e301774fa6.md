# 調査結果（Claude Code 記入・2026-07-22・読み取り専用・コード変更なし）

## 1. HPの実態

- job別基礎値（`BATTLE_TUNING.jobHp`）：**戦士120／見習い盾役110／斥倥99…ではなく実値は『斥倥90』／薬草師80**（タスク文の「斥倥99」は誤記）。未知job用 `defaultHp: 100`。
- **HPへの補正は一切なし**：`maxHp = jobHp[a.job] ?? 100` のみ。性格・前職・stat・武器はHPに影響しない。
- 5人の実HP：ミナ90／ガッド120／エルネ80／ロウ110／**エルシーは対象外**（fightersは `species!=="dog"` のみ。HP・被弾・状態語なし）。

## 2. 与ダメージの実態

- 式：`offense = Σ生存者( combat×4 + weapon.power×2 )`（係数は offensePerCombat=4 / offensePerWeaponPower=2）。**生存者のみの合計**なので誰かが倒れると火力が下がる。
- `dealt = round(offense × variance)`、varianceは一様0.85〜1.15。敵HPはこの `dealt` で減算。
- 按分（スライス1・表示用の派生値）：`personDealt = round(dealt × 個人寄与/offense)` ＝実質「個人寄与×variance」。0のときは記録しない。丸めのため按分合計≠dealtが数ポイントあり得る（エンジンはdealtで減算、表示は派生値）。
- 個人の与ダメ実レンジ（現マスター値）：ミナ7〜9／ガッド15〜21／エルネ7〜9／ロウ12〜16。フル4人合計41〜55/R（スクショの7〜19と整合）。
- 参考：ドラマ層の大ヒット「！」閾値は与ダメ≥14 → 現実に届くのはガッドとロウのみ。

## 3. 現行 stat の実値

- 保存場所：マスター＝`data-adventurers.js` の `stats`（全員11stat）。実行時＝`state.adventurers`（localStorageとマージ）。成長は遠征帰還時に+1、上限 `GROWTH_STAT_MAX=5`。**戦闘は state 経由の party を受け取るので成長後の値が反映される。**
- 参照経路：`a.stats?.combat ?? 1`、`a.stats?.courage ?? 3`、`a.stats?.support ?? 1`（スライス5）。**survival も `a.stats?.survival` で同一経路で取れる**（現在戦闘では未使用）。
- 実値は下の一覧表参照。

## 4. 被ダメ配分の実態（今回は変更しない・把握のみ）

- 前衛決定 `pickBattleFront`：**生存者のみ**を `frontOrder`（戦士→盾役→斥候→薬草師、未知jobは末尾）でソート、同順位は courage 降順。**毎ラウンド再計算**＝前衛が倒れたら次点が繰り上がる。
- `incoming = threat × variance`。前衛60%（frontDamageShare 0.6）、残り40%を他の生存者で等分。単独時は前衛100%。
- 個人被ダメ = `max(0, round(share − weapon.guard))`。guard実値：ミナ2／ガッド3／エルネ3／ロウ5。
- 敵実値：納屋 threat26/HP140／野盗 threat30/HP170。野盗戦・ガッド前衛の実被弾＝約12〜18/R。後衛（残り40%を3人等分−guard）＝ミナ1〜3／エルネ0〜2／ロウほぼ0。
- フル編成の想定決着：野盗HP170 ÷ offense48 ≈ 3.5R。

## 5. 回復（スライス5）との関係

- `healAmount: 15` 固定。maxHp比：ガッド12.5%／ロウ13.6%／ミナ16.7%／エルネ18.8%。
- 重みの直感：前衛（ガッド）の実被弾1ラウンド分（12〜18）とほぼ等価。
- 状態帯との関係：手負い閾値＝maxHpの70%（ガッド84）。+15は「手負い→健在」の戻りを起こしやすく、「深手→健在」は全キャラで数学的に不可（35%+15は70%に届かない）。
- 方咑2への含意（事実のみ）：HPをstat由来にすると固定15の相対重みがHPによって変わる。またstage判定（lightWoundRatio 0.15＝パーティ総HP400の15%＝総被弾60以下で「軽」）に対して回復15は境界の1/4を動かす（スライス5で観測した無傷勝兰70%化の機序）。

## 気づいたこと（式の提案ではなく事実の指摘）

1. **HP=survival由来にする場合の重要な食い違い**：現行HP序列は「ガッド120＞ロウ110＞ミナ90＞エルネ80」だが、survival序列は「ミナ・ロウ2 ＞ ガッド・エルネ1」。**最大HPのガッドがsurvival最低タイ**なので、単純係数（survival×k）では現行スケールを再現できない。job基礎値＋survival補正のような形が必要になるはず（式はチャットClaudeに委ねる）。
2. 攻撃側はすでに「combat×4＋武器power×2」の stat 由来。方咑2の「攻撃=combat由来」は実質達成済みで、未着手なのはHP側のみ。
3. offenseは生存者のみの合計（倒れると火力低下）― 方咑2でも維持したい性質。
4. ドラマ層の「！」閾値（与≥14/被≥10）は現行レンジ（7〜21）前提の固定値。stat成長や方咑2でレンジが変わると意味が変わる（要再考）。
5. タスク文の「斥候HP99」は誤記で実値は90。また weaponGuard のおかげでロウの後衛被弾はほぼ常に0（guard5＞後衛シェア4弱）。
