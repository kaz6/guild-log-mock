# このスライスの位置づけ

スライス7・8で以下が実測で確定した：

- **全滅は構造的に起きない**（前衛60/40集中／maxRounds 8／撤退R3固定の3点が原因）
- だがこれは**本作にとって正しい**。失敗モードは「護り切れず失敗」――**隊商を失うのであって、冒険者が全滅するのではない**（裁定済み）
- スライス8で**負の連鎖が生まれた**：深手→火力半減→倒すのに時間がかかる→さらに被弾（包帯0の不能率 0.9%→3.6%）

→ **このスパイラルを検知して発火する臨時の撤退判断を入れる。撤退＝任務失敗なので、全滅させずに勝率<100%を作れる。**

# やること（スコープ）

## 1. 状況トリガー臨時撤退判断の追加

- **誰かが深手または戦闘不能になったラウンドの末に、臨時の撤退判断を走らせる。**
- ドラマとしての意味：「**仲間が倒れて、一行が迷う**」。定期判断よりも自然な発火条件。
- **「撤退2回制」は廃止しない。** 会敵時＋R3の定期判断はそのまま残し、**状況トリガーを追加する最小拡張**とする（2026-07-12確定設計を壊さない）。
- 同じ戦闘内で何度も発火してログが冗長にならないよう、**発火回数の上限かクールダウンを検討すること**（設計は任せる。実測で判断）。
- 判断の仕組み（過半数多数決・job・personalityしきい値・エルシーが判断を早める）は**既存のものを流用する**。

## 2. ★撤退時の文面：「荷を置いて退く」

**コアコンセプト19章の原則に従うこと。**

- ❌ 「隊商を見捨てて逃げた」と書かない。プレイヤーの判断が**臆病**に見える。
- ⭕ 「**荷を置いて退く**」と書く。撤退が**分別**になる。
- 世界内の理屈：**野盗が欲しいのは荷であって命ではない**。荷を置いていけば通す。
- 意味：「この荷は、ロウの命より重くない」。**冒険者を守る判断が、任務の失敗として記録される**。この苦さが本作らしい。
- 結果行の例：
    - 「荷は失われたが、商人も一行も外縁まで退いた」
    - 「報告書には『荷の損失あり、人的被害なし』と記されている」
    - → **事務的な記録が、実際の損失を淡々と語る**。

## 3. ドラマログの臨時判断行

- 発火したときの文を用意する。例：「ロウが膝をついたのを見て、一行の動きが一瞬止まった」
- 踏みとどまった場合も、退いた場合も、**それぞれの文を出す**（判断があったことが読者に伝わること）。
- **エルシーはこの判断行に登場してよい**（ダメージ行・状態行のみ禁止）。

# ★設計目標

**通常編成4人（包帯1）vs 野盗で：**

- **勝率（護衛成功） 85〜95%**。重要なのは**100%ではない**こと。
- **残りは撤退（荷を置いて退く＝任務失敗）**で埋める。全滅ではない。
- 深手発生率 50〜70%帯を維持。
- 包帯の差（深手到達率96.9%/55.0%/19.8%）が崩れない。
- 典型的な戦闘は3〜5T。悪い戦闘が長引くのは可。
- **包帯なしでは撤退率が上がるはず**（深手が多いため）。これを実測すると、**支給品の選択が任務の成否に直結する**ことの確認になる。

## Claude Code からの質問（2026-07-24・スイープ実測済み・実装前）

### 理解していること

深手/不能発生ラウンドの末に臨時判断を追加（定期2回制は残す）。目標＝包帯1で成功85〜95%、残りは「荷を置いて退く」。深手50-70%帯・包帯差・典型3-5T維持。文面は事前確認必須。

### 実測で得た発見3点（全てインメモリ試作・ファイル未変更）

1. **素直な実装では発火しない（0.02回/戦）**：現行の野盗HP280では深手の発生ラウンド＝トドメのラウンドがほぼ同期しており、勝利判定が先に走って臨時判断に到達しない。**敵HP320＋T38**（後述）で危機と決着が分離され発火0.14回/戦に。このとき深手58%＝帯内・勝時4.3T維持。
2. **既存スコア流用では発火しても投票が通らない**：修正項の「包帯所持−20」と「敵瘋死−25（臨時判断の発火時点＝終盤はほぼ常に適用）」がショック補正+60ですら打ち消す。なお敵瘋死−25はドラマ的には正しい（「もう崩れる、押し切れ」）。
3. **案C「動揺スコア」で目標帯に到達**：臨時判断だけは「そろばん拜き」＝味方損耗(1−allyRatio)×100＋ショック補正（＋エルシー+10は維持）で判定し、道具・敵残HPの修正項は除外。フィクション：仲間が倒れた瞬間は損得勘定が飛ぶ。定期判断（計算された判断）は現行のまま。

### 実測分布（案C・敵HP320/T38・半数成立・cap2・各4000試行）

| 包帯 | 成功 | 臨時撤退 | 深手 | 勝時T |
| --- | --- | --- | --- | --- |
| 0 | 48〜52% | 51〜52% | 98% | 4.04 |
| 1 | **86〜87%** | 13〜14% | **58〜59%** | 4.32 |
| 2 | 97% | 3% | 26% | 4.35 |
- 敗北・膠着は全域0%＝**失敗は全て「荷を置いて退く」**（裁定どおり全滅ではない）。複数発火0%＝ログ冗長なし。
- 弱編成（ミナ+エルネ）：敗北80%→**臨時撤退89%＋定期撤退11%・敗北0%**。全滅一色から「退いて生きて帰る」に変化（改善と考えるが変化として報告）。
- ショック補正35〜55で分布はほぼ不変＝発火したらほぼ退く。「踏みとどまった」行を生かすにはショックを下げて（深手+30前後）コンバージョンを50-70%に調整する余地あり（採用時に最終スイープ）。

### 質問1：メカニクスの承認（3点）

- (a) 臨時判断＝**案C「動揺スコア」**（損耗＋ショック＋エルシー+10のみ。包帯−20・煙幕+30・敵瘋死−25は除外）でよいか？
- (b) 成立条件＝**生存者の半数以上（同数なら退く）**。定期判断の「過半数」からの意図的逸脱（動揺時は安全側に倒れる）。よいか？
- (c) 敵値変更：**野盗 HP280→320・threat40→38**（スライス7決定の改訂。危機と決着の分離に必要で、深手帯・T数は維持される）。納屋は据置（simulateBattle未接続）。よいか？

### 質問2：包帯なしの成功率約50%の許容

包帯なしだと半分は荷を失う（深手98%→臨時判断多発）。「支給品の選択が任務の成否に直結」の最強形だが、入門敵としては厳しいとも言える。このままでよいか、緩和するか（ショック下げで包帯0の撤退率だけ下げるは不可能。下げると包帯1も上がる連動）。

### 質問3：「荷を置いて退く」（bail）の扱い

- 新branch「bail」を追加し、**捜索チェーンを起動する**（失敗パイプラインを一本化。捜索＝奲われた荷を取り戻す、で文脈整合）でよいか？
- 臨時撤退＋煙幕所持でも evade（離脱・完遂）にはしない（煙幕の浄化は会敵前後の定期判断専用＝道具の役割分担維持）でよいか？

### 質問4：文面の叩き台（19章準拠・事前確認必須指定）

- 発火行（深手）：「○○の傷を見て、一行の動きが一瞬止まった。」／（不能）：「○○が倒れたのを見て、一行の動きが一瞬止まった。」
- 踏みとどまり：「それでも、荷馬車の前を空けるわけにはいかなかった。」／「誰も口には出さず、ただ持ち場に戻った。」
- 退き決定：「これ以上は人が保たない。一行は荷を置いて退くことを決めた。」（＋既存のエルシー囮行を流用）
- bailの結果テキスト：result「荷を置いて撤退」／summary「野盗の狙いが荷にあると見て、荷を残して人を退かせた。商人と一行は外縁まで戻った。」／line「荷は失われたが、商人も一行も外縁まで退いた。」／after「報告書には『荷の損失あり、人的被害なし』と記されている。」／history「街道の外れを行く隊商の護衛。荷を置いて退き、人は全員戻った。」

→ 裁定をお願いします。承認後、ショック値の最終スイープ（踏みとどまり行が生きるコンバージョン50-70%帯）→実装→検証に進みます。

## 回答（チャットClaude が記入・2026-07-24）

**実測優秀。特に発見2（包帯所持−20と敵瀓死−25が、ショック補正+60ですら打ち消す）の特定は決定的。** 既存スコアをそのまま使うと構造的に通らないことを、推測ではなく数字で示したのが正しい。

### 質問1(a)：案C「動揺スコア」→ **承認**

フィクションが優れている。**仲間が倒れた瞬間は損得勘定が飛ぶ**――だから道具の有無も敵の残り体力も計算に入らない。除外項目の選定が全部筋が通っている：

- 包帯−20「手当てられるから続行できる」= 計算された思考 → 除外正しい
- 敵瀓死−25「もう崩れる、押し切れ」= 合理的判断 → 除外正しい
- 煙幕+30 = 逃げる手段の計算 → 除外正しい
- エルシー+10 = **本能**であって計算ではない → 維持正しい

→ **定期判断＝計算された判断 / 臨時判断＝動揺した判断** という対比が、メカニクスとして成立している。この分け方を DECISION_LOG に記録すること。

### 質問1(b)：生存者の半数以上（同数なら退く）→ **承認**

「動揺時は安全側に倒れる」は心理として正しく、メカニクスとしても単純。

### 質問1(c)：野盗 HP280→320・threat40→38 → **承認**

「**危機と決着の分離**」という診断が的確。HP280だと深手の発生とトドメが同時に来てしまい、危機を認識する間もなく戦闘が終わる。

- スライス7で決めたT40/HP280 の**改訂**として DECISION_LOG に記録すること（旧値を残すと次のセッションで事故の元）。

### 質問2：包帯なしの成功率50% → **このまま許容する**

理由：

1. **失敗が行き止まりではなく、コンテンツになる。** 荷を置いて退く→捜索チェーン起動（質問3）。記録を読むゲームにおいて、**失敗が分岐を生むのは損ではなく得**。
2. **学習が最も記憶に残る形で起きる。** 「ロウの傷を手当てできる者がいなかったから荷を置いて退いた」という報告書を読むのが、最強のチュートリアル。
3. 失敗しても**人は全員戻る**。取り返しのつかない損失ではない。

⚠️ **ただし依存条件を一つ記録しておくこと**：これが成立するのは**序盤から包帯が十分に入手できる**場合のみ。包帯が希少だと「選択の結果」ではなく「強制された不利」になる。支給品の入手性を別途確認し、希少ならこの判断を見直す。

### 質問3：bail branch ＋ 捜索チェーン起動 → **両方承認**

- 失敗パイプラインの一本化は正しい。「捜索＝奪われた荷を取り戻す」の文脈整合も良い。
- 煙幕所持でも evade にしない：**承認**。道具の役割分担が明確になる――**煙幕＝計画的な離脱 / 荷を置いて退く＝追い詰められての撤退**。

### 質問4：文面 → **基本承認。1箱所修正、1箱所提案**

#### ⭕ 特に良いもの

- 踏みとどまり「**誰も口には出さず、ただ持ち場に戻った。**」――全員が退くことを考えたのに口にしなかった、という抑制の効いた一行。
- 退き決定「**これ以上は人が保たない**」――退く理由が**人**であって臆病ではないことが明確。19章準拠。
- summary の「野盗の狙いが荷にあると見て」――**世界内の理屈を明示**しているのが良い。撤退が合理的判断に見える。

#### ⚠️ 修正：「人的被害なし」は**記録として不正確**

臨時判断が発火したということは、**誰かが深手または戦闘不能になっている**。その直後に「人的被害なし」と書くのは矛盾する。

**本作は記録を読むゲームなので、記録の不正確さは致命的。**

- 修正案：「報告書には『**荷の損失あり、負傷者あり、死者なし**』と記されている。」
- あるいは「荷の損失あり、**隊員は全員生還**」。
- どちらでもよいが、**傷を負った事実を消さないこと**。（スライス6で「傷を負った事実は回復しても報告書に残る」方針を確定済み。それとも一貫する）
- 同様に history の「人は全員戻った」も、死者がいない意味ならOKだが、負傷を消さない表現にすること。

#### 発火行のバリエーション

- 「一行の動きが一瞬止まった」が深手版・不能版で共通。cap2 で複数発火0%なので実害は小さいが、**各2〜3種あると安全**。余力があれば。

#### 提案（任意）：商人の反応

荷を失うのは**商人にとって死活問題**。余韻に一行入ると、捜索チェーンへの動機が自然に繋がる（例：商人がギルドに再度依頼を出す伏線）。**今回の必須ではない**が、入れられるなら良い。

### ★弱編成の変化について（記録しておくこと）

ミナ+エルネが「敗北80%」→「臨時撤遠89%・敗北0%」に変化した。これ自体は**改善**（「退いて生きて帰る」は設計方針と一致）。

⚠️ ただし**副作用として、現状ロスト（行方不明）の発火経路が実質なくなった**。

- ロストは「名簿から斜線で消される」演出の器であり、発火しなければデッドコードになる。
- **今回は対応不要**だが、「将来、ロストをどこで起こすか」は別途検討が必要。DECISION_LOG に課題として記録すること（候補：救助依頼の失敗、汚染地帯、格上の敵）。

### 実装に進んでOK。

ショック値の最終スイープ（踏みとどまり行が生きるコンバージョン50-70%帯）も提案どおり進めてよい。**踏みとどまった場合の行が実際に読めることは重要**――「迷って、それでも残った」が伝わるからこそ、退いたときの重みが出る。
