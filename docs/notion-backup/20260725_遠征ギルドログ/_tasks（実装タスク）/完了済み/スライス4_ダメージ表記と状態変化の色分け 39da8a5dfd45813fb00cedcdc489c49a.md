# やること（スコープ）

戦闘ドラマログに、**数値の単位表記**と**状態変化の色分け**を入れる。両方とも表示層の変更なので同時にやる。

## 1. 数値に「ダメージ」を明記する

現状の `（野盗に-15！）` だと**初見で何の数値か分からない**。

- **変更後の形式：`（野盗に15ダメージ！）` `（ロウに1ダメージ）`**
- **マイナス記号は削除する。**「ダメージ」と書けば減少は自明なため。
- 大ダメージ時の「！」は従来どおり末尾に付ける。

## 2. 状態変化の色分け

「ヤバさ」を強調したい。状態変化行を色で区別する。

| 対象 | 色 |
| --- | --- |
| **戦闘開始の一文**（例：「荷を狙う野盗が、数を頼りに街道へ出てきた。」） | 赤 |
| **手負いへの遷移**（例：「ロウの息が上がってきた。」） | オレンジ |
| **深手への遷移**（例：「ロウの構えが崩れた。もう長くは保たない。」） | 赤 |
| **戦闘不能への遷移** | 赤（深手と同じ扱いでよい。別の見せ方があれば提案して） |

### 色分けの制約

- **視認性を必ず担保する。** 背景が暗い（ダークテーマ）ので、暗い赤・暗いオレンジは使わない。
- 実機（スマホ・ダーク背景）で読めるコントラストを確保すること。
- やりすぎない。**背景色を変えたり、行全体をハイライトしたりしない**。文字色の変更のみ。

## Claude Code からの質問（2026-07-14・実装前の確認）

### 理解していること（相違があれば指摘ください）

- ダメージ表記：`（野盗に-15！）`→`（野盗に15ダメージ！）`。マイナス削除、大ダメージの「！」は維持。対象はドラマログの与ダメ・被ダメ・トドメの全行（数値付きの行は他にないことをgrepで確認済み）。
- 色は**文字色のみ**：戦闘開始の一文＝赤／手負い遷移＝オレンジ／深手・戦闘不能遷移＝赤。背景色・ハイライト・サイズ変更・アニメはしない。戦闘以外のログには色をつけない。
- 実装方式：ログ行は `<div class="log-line ${kind}">` で描画される既存機構をそのまま使う。ドラマログ生成側が行ごとに kind（通常=action／開始=battle-start／手負い=status-hurt／深手・戦闘不能=status-grave）を返し、style.css に3クラス追加。戦闘開始の一文は遭遇フリ（generateCaravanEscortLogs）の末尾行なので、そこだけ battle-start を付与。時系列・トドメ最後・エルシー非登場は不変。

### 質問1：色のhex叩き台（ダーク背景 #17120f＋ログ行の淡いクリーム重ねで実測）

- **赤（戦闘開始・深手・戦闘不能）：`#ff6b5b`** ― 実効背景とのコントラスト比 約6.0:1（WCAG AA基準4.5:1を充足）。暖色寄りの明るい赤で、本作のアンバー基調（--accent #c9964a）と喧嘩しにくい。既存 --danger（#d98a64）はくすみ過ぎて「ヤバさ」が出ないため不採用。
- **オレンジ（手負い）：`#ffa94d`** ― コントラスト比 約8.9:1。赤との区別もダーク背景で明瞭。

### 質問2：戦闘不能の見せ方

- 推奨：**深手と同じ赤（#ff6b5b）**。理由：深手→戦闘不能は連続して出がちで、色の段差より文章（「膝をつき、そのまま動けなくなった」）の方が事実を伝える。強調を足すなら次の演出スライス（サイズ・揺れ）が適切な居場所。
- 代案がよければ：より白っぽい赤 `#ff8d80`（深手より一段「抜けた」感）も用意できる。
