# 問題：損耗が火力に反映されていない

スライス7の実測で、以下の2つが**threat調整では構造的に不可能**と確定した：

- **勝率がどのthreatでも100%**（T54で不能43%ですら勝利100%）
- **通常編成の撤退が0%**

**両方の根本原因は同じ：味方DPSが減衰しない。**

- 傷ついても誰も弱くならない → 予定どおり敵を削り切る → **負けない**
- 戦況が悪化しないまま第2判断が来る → スコアが伸びない → **撤退しない**

# やること（スコープ）

**損耗による与ダメ低下を導入する。**

## ★連動させる対象：状態語（段階的）

```
健在：与ダメ 100%
手負い：与ダメ 80%（叩き台）
深手：与ダメ 50%（叩き台）
戦闘不能：行動しない（現行どおり）
```

- **HP比率に連続的に連動させるのではなく、状態語に段階的に連動させる。**
- 理由：本作は**報告書を読むゲーム**なので、**因果が読めることが最優先**。連続的だと「なんとなく削りが遅くなった」で終わるが、段階的なら**赤文字の状態行と、その後の数字の落ち込みが直結**する。
- 副次効果：**回復の価値が跨ね上がる**。深手→手負いに戻せば火力も戻る。エルネが「傷を治す人」から**「戦線を維持する人」**になる。

## ★表現の方針（重要）

- **システムの説明をしない。** 火力低下は**数値と描写で自然に伝わればよい**。
- ❌ 禁止：「ラウンド」「次のラウンドから削りが落ちた」のような**メタなシステム用語**。ラウンド番号を表に出さない方針（案D）と矛盾する。
- ❌ 禁止：「手負いなので攻撃力が下がった」のような**仕様の直接記述**。
- ⭕ 良い例：「ガッドの一撃は、さっきほどの重さがなかった（野盗に14ダメージ）」――**傷の影響が動作に出る書き方**。
- 数字は既に見えている（24→14のように落ちる）ので、文章で説明する必要はない。
- ※ 不調を示す文脈のテンプレを追加するのはよいが、**新しい語彙の大量追加はしない**（最小差分）。

## 係数のスイープ

### 理解していること

### 実測（全てインメモリパッチ・ファイル未変更・各4000〜5000試行）

1. **mult(0.8/0.5)×T40〜48×HP280**：勝率全て100.0%。深手56〜96%、勝時3.97〜4.01T。損耗単体ではターン数すらほぼ伸びない（深手が出る頃には敵HPの8〜9割を削り終えている）。

3. **強襲ラウンド試作**（確率Pで敵攻撃M倍：P0.10-0.15×M1.6-1.8×HP280-340）：不能40%帯でも**勝率100.0%**。

### ⚠構造的結論：「勝率85〜95%」は今回のノブ（mult・threat・敵HP・強襲）では到達不可能

敗北・膠着が起きない理由3点（実測で確証）：

1. **被ダメ60/40の前衛集中で全滅が直列にしか進まない**。後衛は毎ラウンド4〜8ダメージしか受けず、倒すには10ラウンド以上必要。4人全滅は構造的に間に合わない。
2. **maxRounds 8 は半壊パーティでも削り切るのに十分**。2人残りでも累計火力が敵HPを超える＝膠着にならない。
3. **撤退はR3固定で、崩壊（R4以降）の前に判断が終わっている**。R3時点のスコア実測≤≈20 vs 必要≥75。

（なお「発火しなければ実測値と原因を記録」の指示に従い、撤退＝通常編成0.00%・原因＝上記3を記録します）

## 回答（チャットClaude が記入・2026-07-24）

**実測優秀。特に「HP400/T48・不能94.7%ですら勝率100%」の検証は決定的。**

### ★重要な再解釈：これは壁ではなく、設計からの答え

「4人全滅が構造的に起きない」のは、**このゲームにとって正しい可能性が高い**。

- 本作の4段階結末の失敗モードは「**護り切れず失敗**」――つまり**隊商を失うのであって、冒険者が全滅するのではない**。
- 原体験（MPO：無事に帰ってくるだろうかと待つ）の緊張も、「死ぬか」ではなく**「任務を果たせるか、どんな姿で帰るか」**。
- 行方不明（ロスト）は**名簿から斜線で消される演出**の器であり、希少だから重い。频発していいものではない。

→ **だから「勝率<100%」は全滅ではなく、任務失敗で作るのが正解。** この読み替えを確定とする。

### 質問1（スコープの裁定）：**A案を採用**

今回は損耗DPS低下（mult 0.8/0.5）＋深手の弱撃描写だけを入れる。完了条件の「勝率85-95%」「撤退＞0」は**再繰延（実測と原因を記録済み）**と読み替えてよい。

### ★次スライス案「状況トリガー臨時撤退判断」を**強く支持する**

提案どおり、誰かが深手/不能になったラウンドの末に臨時の判断を追加する方向で進める。理由：

1. **撤退＝護衛失敗なので、全滅させずに勝率<100%を作れる**（上記の再解釈と一致）。
2. **「撤退2回制」を廃止せず、状況トリガーを足すだけの最小拡張**。確定済み設計（2026-07-12）を壊さない。
3. **ドラマとして正しい**。「仲間が倒れて群れが迷う」は、定期判断よりも自然な発火条件。
4. 今回のDPS低下と**相乗する**：深手→火力半減→戦況が本当に悪化→そのラウンド末に判断が走る。因果が繋がる。

### ★もう一つの構造的原因を記録しておくこと

実測で挙げられた3点のうち、**①前衛60/40集中で後衛が死なない**は、保留中の**方咑2・第二弾（被ダメ配分のstat駆動化・前衛ローテーション）**の領域。

- もし将来本当に全滅を起こしたくなったら、そこがレバーになる。
- **ただし現時点では全滅を起こしたいわけではない**ので、「レバーの所在」として記録するに留める。

### 質問2（描写の叩き台）：**採用。ただしバリエーションを増やす**

- 方向は良い。手負いは専用文なし（数字の落ち込みだけで語る）も正しい。
- ⚠️ **ただし2種は少なすぎる。** 深手は56%発生し、かつ**1つの戦闘内で複数回行動する**ので、同じ文が同じ報告書に2回並ぶ。**3〜4種に増やすか、連続で同じ文を使わないルールを入れること。**
- 「！」の期待値を弱体後基準にするのは**良い判断**。「傷を押してなお重い一撃」が出るのはドラマとして優れている。

### 質問3（採用係数）：**全てOK**

- mult 手負い0.8／深手0.5：採用。分布差が僅少なら**因果の読みやすさでキリのよい値**を選ぶのが正しい。
- threat T40据置き・納屋T38据置き：OK。
