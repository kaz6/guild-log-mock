# 発見された崩れ（実機スクショより）

- 「**くか一瞬だが**、隊商を置くのはいけないと、一行は踏みとどまった。」
    - 「**退**くか一瞬だが」の先頭が欠落している
- 「ロウはよろけた拍子に、野盗の一撃を**戦場に**受けた！」
    - 「**まともに**受けた」のはず。別の語に置換されている
- 「幾人かは傷を**失った**が、隊商は止まらずに外縁の先へ抜けた。」
    - 「傷を**負った**」のはず
- 「エルネ・シェルカは戦い慣れない様子で、**一方棒を振った**（野盗に-7）」
    - 「一方」が不自然。語の混入の可能性

# 仮説（調査の取っかかり。断定ではない）

**少なくとも2系統あると見ている。**

## 系統1：語彙プールの混線

- 「まともに / 戦場に」「負った / 失った」は、**正しい語が別の語に置換されている**パターン。
- `pick([...])` のランダム語彙選択で、**別の文脈用の語彙が同じプールに入っている**可能性。
- → 共有テキストプールの管理問題。過去の「低緊張クエストへの戦闘語彙漏洩」と同じ構造。

## 系統2：先頭欠落

- 「くか一瞬だが」は先頭が消えている。文字列結合か `slice` のミスの可能性。
- 語彙選択とは別の原因と見られる。

# 監査結果（Claude Code 記入・2026-07-14・読み取り専用フェーズ）

## 結論（先に要旨）

**崩れはソースコードに存在しない。コード起因の2仓説（プール混線／先頭欠落）はともに棄却。最有力は「端末ブラウザのページ翻訳（自動翻訳）による表示層での書き換え」。**

## 崩れの一覧（未発見分を含む）

- 視認された4件：`grep` で現在の全ファイルに**存在せず**。`git log -S`（全履歴検索）でも「戦場に受け」「傷を失った」「一方棒」は**一度もコミットされたことがない**。正しい文面（まともに受けた／傷を負った／それでも棒を振るった／退くか一瞬迷ったが）は app.js 4397/4483/4499/4528 に健在。
- 未発見の崩れ：ドラマログ・結果テキストの全テンプレ目視監査で誤字ゼロ。実DOM再現テスト（編成3種を回して120試行、8,688行を検査）で崩れ文字列の出現**0件**、対象4テンプレは各67〜106回正しく出現。

## 原因の分類（タスクの分類軸に沿って）

- **単発の誤字**：該当なし（テンプレは全部正しい）。
- **語彙プールの混線（仮説系煱1）**：棄却。ドラマログの pick() プールはすべて各文脈の関数内インラインリテラルで、**共有プールがそもそも存在しない**（混線の物理的経路なし）。
- **文字列結合・切り出しのミス（仮説系煱2）**：棄却。ログ文を触る `.replace()` は0件、slice/substr もログ文には未使用。後処理4関数（withElsieLog / appendPresence / appendBanter / appendGrowth）は**行の挿入のみ**で既存テキストを書き換えない。escapeHtml はHTMLエスケープのみ。
- **デプロイのずれ**：棄却。GitHubの main ＝ 作業ツリー ＝ cf684a7 で一致。そもそも崩れ文字列はどのコミットにも存在しないので、古いキャッシュでも説明不能。
- **その他＝表示層（最有力）**：**端末ブラウザのページ翻訳によるテキストノード書き換え**。根拠：
    1. 崩れ方が機械翻訳の署名そのもの。「負った→失った」（漢字「負」を「負ける/lose」と誤読する典型的な往復翻訳エラー）、「それでも→一方」（接続語の言い換え）、「振るった→振った」（表記正規化）、「まともに→戦場に」（文脈語の幻覚）、「退くか一瞬迷ったが→くか一瞬だが」（分かち書き解釈の崩壊）。
    2. 崩れた4行は**別々の生成関数2つ**（ドラマログ関数＋結果テキスト関数）にまたがる。単一のコード経路では説明できず、ページ全体への変換だけが4件を一度に説明する。
    3. index.html は `lang="ja"` はあるが **`translate="no"` / `<meta name="google" content="notranslate">` が無い**。動的に innerHTML で流し込む本文はブラウザ翻訳の再処理対象になりやすい。
    4. ローカルの同一コード（＝配信中の main）では120試行・8,688行で一度も再現しない。

## 他のクエストへの波及

- コード起因ではないためコード側の波及はなし。ただし翻訳が原因なら**全画面の全テキストが同じリスク下にある**（戦闘ログは文が長く不自然さに気づきやすかっただけ）。過去の「低緊張クエストへの戦闘語彙漏洩」とは異なる構造。

## 修正方針の提案（確認待ち）

1. **index.html に翻訳抑止を宣言**（最小差分）：`<html lang="ja" translate="no">` ＋ `<meta name="google" content="notranslate">`。本作は「文章そのものがゲーム」なので、機械翻訳は体験を壊す＝全ページ翻訳抑止が妥当と判断。
2. **実機での裏とりを作者に依頼**：スマホのブラウザで当該ページに翻訳バー／翻訳中表示が出ていないか、メニューの「日本語に翻訳」が有効になっていないか確認。UIラベル（依頼掲示板等）も微妙に変わって見えていたはず。
3. テンプレの文面変更は不要（壊れていない）。
