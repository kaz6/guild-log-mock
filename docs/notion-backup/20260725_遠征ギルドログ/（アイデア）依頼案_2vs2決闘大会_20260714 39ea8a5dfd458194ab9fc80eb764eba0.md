# 依頼の概要：2vs2 の決闘大会（イベント依頼）

- 依頼掲示板に**決闘大会の告知**が表示される。
- 最低2人を送り込む。**ただただ戦う**（シンプルな戦闘ミッション）。
- 優勝したら**賞金**がもらえる。
- 負けても**経験値・成長**は得られる（参加するだけでメリットがある）。
- 定期的に出現する。

# 性格づけ：ラッキー依頼

- 通常依頼とは別の、**特殊なラッキー依頼**の位置づけ。
- リスクの割にリターンが良く、**「見かけたら積極的に参加するといいよ」**と思わせる設計にしたい（負けても損をしにくい）。

# 他プロジェクトとのリンク（このアイデアの真の狙い）

- **他のプロジェクト（格ゲー等）でやっている要素とリンクさせておくと、後々フラグになって楽しい。**
- プロジェクト横断の仕掛けを積極的に出していきたいという方針の一環。
- 決闘大会はその最初の一個として適している（戦闘という题材が格ゲープロジェクトと相性が良い）。

# 将来の拡張：絆システムとの連携

- 戦闘を有利にする条件として、**冒険者同士の信頼度・友好度・絆が高いもの同士で送ると勝率が上がる**、という仕組みにしたい。
- これにより「誰と誰を組ませるか」に意味が生まれる。
- **前提**：信頼値システム（第3のナラティブ層）は既に設計済み（未実装）。それと接続する。
- ここは将来的な要素。信頼値システムが実装されてから。
