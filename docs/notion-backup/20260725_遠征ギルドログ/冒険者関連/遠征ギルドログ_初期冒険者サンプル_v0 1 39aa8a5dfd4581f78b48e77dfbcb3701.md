## 1. 結論

初期冒険者3人は、以下の役割が一目で分かるようにする。

1. 戦闘担当: 討伐・護衛に強いが索敵が苦手
2. 探索担当: 霧の森・救助・道案内に強いが戦闘は普通
3. 治療担当: 薬草・毒・救助後方支援に強いが打たれ弱い

この3人で、MVP初期ミッショ5件すべてに対して「誰を出すか」「何を持たせるか」を判断できる。

## 3. 個別データ

### 3.1 ロイド

adventurer_id: ADV_ROID_001 / job_id: JOB_WARRIOR / personality_id: PER_BRAVE / background_id: BG_SOLDIER / state: 待機 / compatibility_tag: 前へ出る、仲間を庇う

**フレーバーテキスト**：村の衛兵隊にいた若い戦士。腕は立つが、誰かが危ないとすぐ前に出てしまう。本人は「これくらい大丈夫です」と笑うが、ギルドの記録係からはよく怒られている。お金を稼いだらパン屋を開きたいと思っている。

**能力値**：HP30、戦闘12、索敗2、野営6、治疗4、運3

**得意ミッション**：小鬼の洞窟の見回り、街道沿いの荷物配達、将来の護衛系ミッション

**苦手ミッション**：霧の森の薬草採集、迷子の新人を探せ、毒草調査

**持たせたいアイテム**：小盾（負傷率低下。前に出る性格と相性が良い）、薬草（勇敢による被弾をフォロー）、杉火（洞窟や霧で最低限の視界を補う）、古い地図（索敵の低さを補うが本人だけでは使いこなせない感じも出せる）

**ログの出しどころ**：仲間を庇う、前に出すぎて負傷する、小盾で一擊を受け止める、勇敢な判断で成功する、索敵不足で罠に気づくのが遅れる

**サンプルログ**：

- ロイドは真っ先に小鬼の前へ飛び出した。仲間が止めるより早かった。
- 小盾が棍棒を受け止めた。腕はしびれたが、ロイドは笑って「大丈夫です」と答えた。
- 足元の罠には気づかなかった。ロイドは戦いには強いが、地面を見るのは苦手らしい。
- 帰還後、ロイドは報告書の負傷欄を見て少しだけ気まずそうにしていた。

**調整メモ**：初期戦闘担当としてかなり分かりやすい。強いが万能ではない。プレイヤーに「ロイドだけでは森や救助は危ない」と理解させる役。

### 3.2 ミナ

adventurer_id: ADV_MINA_001 / job_id: JOB_SCOUT / personality_id: PER_CAUTIOUS / background_id: BG_HUNTER / state: 待機 / compatibility_tag: 足跡を読む、慎重な案内役

**フレーバーテキスト**：森育ちの元猟師。無口で慎重だが、足跡や風向きの変化には誰よりも早く気づく。派手な活躍は苦手だが、帰り道を覚えているのはだいたい彼女である。私服は意外と派手。

**能力値**：HP22、戦闘4、索敂12、野営8、治疗4、運5

**得意ミッション**：霧の森の薬草採集、街道沿いの荷物配達、迷子の新人を探せ、将来の探索・調査系ミッション

**苦手ミッション**：小鬼の洞窟の見回りを単独で担うこと、高戦闘要求の討伐ミッション

**持たせたいアイテム**：古い地図（索敵の強みをさらに伸ばす）、杉火（霧・夜・洞窟で探索ログを出しやすい）、保存食（野営の強みと相性が良い）、短剣（最低限の護身用）

**ログの出しどころ**：足跡を見つける、迷子を防ぐ、帰り道を覚えている、慎重すぎて時間がかかる、危険な道を避ける

**サンプルログ**：

- ミナはぬかるみに残った浅い足跡を見つけた。本人は「まだ新しい」とだけ言った。
- 霧が濃くなったところで、ミナは無言で一行の進路を変えた。理由はあとで分かった。先の橋が落ちていた。
- 保存食を分ける場所を選んだのはミナだった。風よけになる倒木の陰を、彼女は最初から見つけていたらしい。
- 帰り道を尋ねられると、ミナは少しだけ不思議そうな顔をした。覚えていて当然だと思っているようだ。

**調整メモ**：探索・救助の主役。ロイドと組ませると戦闘と索敵が補完される。エルンと組ませると森・薬草・救助で強い。

### 3.3 エルン

adventurer_id: ADV_ELN_001 / job_id: JOB_MAGE / personality_id: PER_TIMID / background_id: BG_HERBALIST / state: 待機 / compatibility_tag: 薬草に詳しい、不安を口にする

**フレーバーテキスト**：薬草採りの家で育った気弱な魔術師。戦いは苦手で、出発前にはいつも不安そうに荷物を確認している。だが毒草や傷の手当てになると、震える声のまま的確な指示を出す。意外にもお酒に強い。

**能力値**：HP17、戦闘4、索敗6、野営4、治疗11、運5

**得意ミッション**：古い薬草園の毒草調査、霧の森の薬草採集、迷子の新人を探せ、将来の毒・呆い・異常調査系ミッション

**苦手ミッション**：小鬼の洞窟の見回り、前衛がいない討伐ミッション、長時間の過酷な遠征

**持たせたいアイテム**：解毒薬（得意分野を強化）、包帯（救助・治療ログを出しやすい）、薬草（前職と噫み合う）、お守り（HPが低いので保険になる）

**ログの出しどころ**：出発前に不安がる、毒草を見分ける、怪我人に包帯を巻く、戦闘では後ろに下がる、いざという時だけ勇気を出す

**サンプルログ**：

- エルンは出発前に、薬草と包帯を三度確認した。それでもまだ足りない気がしているようだった。
- 毒草の棘を見た瞬間、エルンは小さく悲鉱を上げた。だが次の瞬間には、解毒薬の瓶を取り出していた。
- 負傷した新人を前に、エルンの声は震えていた。それでも包帯の巻き方は正確だった。
- 「戦うのは無理です」と言いながら、エルンは倒れた仲間の前に立った。

**調整メモ**：治療・毒対策担当。弱そうに見えるが、救助や毒草調査では替えが利かない。プレイヤーに「戦闘以外の能力も大事」と理解させる役。

## 4. 初朙3人の相性・組み合わせ

**ロイド + ミナ**：ロイドが戦闘、ミナが索敵と帰路確保を担当。向くミッション：小鬼の洞窟、街道配達、軽めの調査。ログ例：「ロイドが前へ出ようとしたところを、ミナが袖を引いて止めた。足元には小さな罠があった。」

**ミナ + エルン**：ミナが見つける、エルンが見分ける/治す。向くミッション：霧の森薬草採集、毒草調査、迷子の新人を探せ。ログ例：「ミナが見つけた葉を、エルンが毒草ではないと確認した。」

**ロイド + エルン**：ロイドが守る、エルンが治す。向くミッション：小鬼の洞窟、毒草調査の護衛付き運用。ログ例：「小鬼が飛びかかった瞬間、ロイドはエルンの前に出た。エルンは震えながらロイドの腕に包帯を巻いた。」

**ロイド + ミナ + エルン**：戦闘、索敵、治療が揃う標準パーティ。5つの初期ミッションを一通り試せる。弱点：運はやや低め、野営特化ではない、ロイドが前に出すぎると負傷しやすい。

## 6. 初期カバン例

**小鬼の洞窟の見回り**：編成 ロイド+ミナ+エルンor新人枠 / カバン 小盾・薬草・杉火 — ロイドの戦闘力を活かしつつ、負傷と暗所を対策する。

**霧の森の薬草採集**：編成 ミナ+エルン+ロイドor新人枠 / カバン 古い地図・杉火・保存食 — ミナの索敵とエルンの治療で、迷子と採集失敗を防ぐ。

**古い薬草園の毒草調査**：編成 エルン+ミナ+ロイド / カバン 解毒薬・包帯・薬草 — 毒事故を彻底的に防ぐ。ロイドは護衛役。

**街道沿いの荷物配達**：編成 ロイド+ミナ+新人枠 / カバン 保存食・古い地図・小盾 — 新人育成向き。ロイドとミナがいればかなり安定する。

**迷子の新人を探せ**：編成 ミナ+エルン+ロイド / カバン 古い地図・杉火・包帯 — 発見、視界、応急処置を優先する。4枠なら保存食、5枠ならロープかお守り。

## 7. 調整したいポイント候補

この3人はかなり役割が分かりやすいが、少しベタでもある。

調整候補：

1. ロイドをもう少し不器用/新人っぽくするか
2. ミナを少女寄りにするか、大人の実務家寄りにするか
3. エルンを魔術師感強めにするか、薬草採り感強めにするか
4. 初朙3人の性別バランスを変えるか
5. 名前をもっと世界観に寄せるか
6. フレーバーテキストを明るめ/暗め/コミカル寄りに調整するか
7. ログをもっと軽くするか、もう少し情緒を強くするか
