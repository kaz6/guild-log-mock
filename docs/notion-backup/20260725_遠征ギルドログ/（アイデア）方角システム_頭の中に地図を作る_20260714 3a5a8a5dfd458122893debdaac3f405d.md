# アイデアの概要

依頼・任務に、場所だけでなく**方角（北部・東部・南部・西部の4つ）**を追記する。

目的は**プレイヤーの頭の中に地図ができていくこと**。記録係が報告書から世界の位置関係を再構築する体験の、空間版。

# 設計の勘所（重要）

**方角が「意味を持つ」には、方角ごとに性格が要る。**

- 単なる位置ラベルだと、プレイヤーは「東部＝道の依頼」と暗記するだけで地図にはならない。
- 地図になるのは、**方角ごとに「らしさ」が積み重なったとき**。依頼の種類から方角を予測できるようになると、頭の中に地図ができる。
- つまり**方角を、位置ラベルではなく「方角ごとの性格（よく出る依頼傾向・世界観）」とセットで設計する。**

# 方角ごとの性格（叩き台・未確定）

- **東部＝人の領域**（街道・都市・交易）→ 生活・輸送・護衛系の依頼が多い。都市部への道の開拓関連は東部に統一。
- **北部＝厳しい自然**（山・寒さ）→ 探索・遭難救助・怪異が多い。
- **西部＝古いもの**（廃墟・遺構）→ 記録・拓本・調査が多い。
- **南部＝未定**（作者にもまだイメージなし。今後埋める）

※ これは叩き台。実際には依頼を作りながら方角の性格を育てていく。一度に全部決めない。

# アンチミーム位置特定との接続（真の狙い）

- 最終的に**アンチミーム（認識できない何か）の位置を、プレイヤーが方角の情報から推理する**――この伏線になる。
- 推理が成立するには、**各方角の「普段の性格」が確立していること**が前提。
    - 例：「西部はいつも古いものの調査なのに、最近やたら別種の異変が報告される」→「西部で何か起きている」と気づける。
    - **普段があるから、異常が浮かぶ。** 方角に性格を持たせるのは、この伏線の土台。

# 地図の扱い

- ゲーム内に地図を登場させるかは**未定**。
- 理想は「プレイヤーの頭の中に地図ができる」こと。地図UIを出さない方が、推理体験としては深い可能性もある（要検討）。

# 未確定・要検討

- 南部の性格。
- 方角を依頼データ（data-quests.js）のどのフィールドに持たせるか。
- 既存依頼への方角の遡及付与（今ある依頼をどの方角に割り振るか）。
- 報告書・掲示板UIで方角をどう見せるか（テキストのみか、アイコンか）。
- 方角ごとの性格と、既存の依頼カテゴリ（生活・輸送・保全・救助・戦闘・記録・調査）の対応付け。

# ★伏線回収先の確定（2026-07-14）

- 方角システムの**最終目的が確定した**：**「忘れられた地」＝アンチミーム（ラスボス）の居場所を特定すること。**
- 方角は雰囲気づけや依頼分類のためだけではなく、**ラスボスの座標**。プレイヤーが各方角の「普段の性格」を把握し、異常が浮かぶことで、最終的に忘れられた地の方角を推理する。
