# やること（スコープ）

`simulateBattle` が、戦闘の結果とあわせて「ラウンドのイベント列」を返すようにする。

既存の戻り値は壊さず、**プロパティを追加する形**で実装する。

## イベント列に含める情報

- ラウンド番号
- 与ダメージ（誰が敵に何ダメージ）
- 被ダメージ（敵が誰に何ダメージ）
- 被弾者の状態語の遷移（健在→手負い→深手）
    - **閾値：個人HP 70%以下で手負い、35%以下で深手**
- 撤退判断が行われたラウンドと、その結果

# 制約

- **エルシーはイベント列のダメージ行に一切登場させない**（与ダメ・被ダメとも）
    - ただしエルシーの撤退判断への影響（判断を早める）は既存ロジックのまま維持
- HP残量の数値そのものはイベント列に含めない（状態語のみ）
- 1依頼1関数構造を維持
- 最小差分を優先
