位置づけ: 成功判定式 v0.1 を、初期冒険者・初期ミッション・初期アイテムに当てはめるテスト表。目的は、実装前に「簡単すぎる/難しすぎる/理不尽/面白い部分成功が出るか」を確認すること。

## 1. 結論

最初の判定式の方向性は良い。ただし、実際に当てはめてみると、重要な問題が1つある。

**問題**：初期ミッションのrequired値が低すぎると、3人パーティの能力合計がすぐ上限補正へ到達し、ほとんど大成功になる。つまり、ミッション要求値は「1人ぶんの目安」ではなく、「3人パーティ合計前提」に調整した方がよい。

**推奨**：MVPでは以下の方針にする。

- パーティ能力は3人合計で見る
- ミッション要求値も　人合計前提で設定する
- 1能力あたりの差分補正は -5〜+5 に丸める
- アイテムなしでも低難度は成功しやすい
- 中難度以上は、担当キャラやアイテムがないと部分成功/失敗が出る
- 救助ミッションは、最初から少し怖くする

## 2. 使用する判定式

mission_score = ability_score + item_score + party_score + random_score - danger_penalty

このテストではrandom_scoreは0とする（まずは平均的な結果を見るため）。

結果ランク：12以上→大成功、5〜11→成功、-4〜4→部分成功、-5以下→失敗

## 5. テストケース一覧

### 5.1 小鬼の洞窟の見回り

**ケースA: ロイド+ミナ+エルン / 小盾・薬草・東明** — ability24 / item7 / party2 / danger-2 / 合計31 → 大成功。評価：初期3人フル投入ならかなり安全。問題ない。

**ケースB: ロイド+汎用新人×2 / 小盾・薬草・東明** — ability21 / item7 / party0 / danger-2 / 合計26 → 大成功。評価：ロイドがいれば低難度討伐はかなり安定する。低難度枠としてはOK。ただし毎回大成功だと単調なので、報酬や称号は控えめにする。

**ケースC: 汎用新人3人 / アイテムなし** — ability18 / item0 / party-2 / danger-2 / 合計14 → 大成功寄り。評価：やや甘い。汎用新人3人アイテムなしで大成功はやや簡単すぎる。調整候補：小鬼の洞窟は成功しやすいが、大成功には戦闘担当または推奨アイテムが必要にする。

## 6. 霧の森の薬草採集

**ケースA: ミナ+エルン+ロイド / 古い地図・東明・保存食** — ability21 / item7 / party2 / danger-4 / 合計26 → 大成功。標準パーティー+推奨アイテムなら安定。OK。

**ケースB: ミナ+汎用新人×2 / 古い地図・東明・保存食** — ability12 / item7 / party0 / danger-4 / 合計15 → 大成功。ミナがいると森系はかなり強い。役割が立っていて良い。

**ケースC: ロイド+汎用新人×2 / 古い地図・東明・保存食** — ability1 / item7 / party0 / danger-4 / 合計4 → 部分成功。ロイドがいて戦闘は安心だが、森の索敌と治療が足りないため、目的は達成しても帰還遅れ/迷子未遂/報酬減が出る。このゲームらしい結果。

**ケースD: ロイド+汎用新人×2 / アイテムなし** — ability1 / item0 / party0 / danger-4 / 合計-3 → 部分成功〜失敗手前。ミナなし・地図なしだと危ない。行方不明未遂や軽症が出やすい。

## 9. 迷子の新人を探せ

**ケースA: ミナ+エルン+ロイド / 古い地図・東明・包帯** — ability3 / item8 / party2 / danger-6 / 合計7 → 成功。適正メンバーと推奨アイテムを揃えても「大成功」ではなく「成功」止まり。救助ミッションの怖さが出る。

**ケースB: ミナ+エルン+汎用新人 / 古い地図・東明・包帯** — ability3 / item8 / party0 / danger-6 / 合計5 → 成功ぎりぎり。戦闘護衛が薄いぶん、成功はするが事故判定に不安が残る。

**ケースC: ロイド+エルン+汎用新人 / 古い地図・東明・包帯** — ability-3 / item8 / party0 / danger-6 / 合計-1 → 部分成功。ミナ不在だと、アイテムがあっても捐索力が足りず、発見は遅れる。救助対象の状態悪化や帰還遅れが出る。

**ケースD: ロイド+汎用新人×2 / アイテムなし** — ability-7 / item0 / party0 / danger-6 / 合計-13 → 失敗。救助ミッションに索敌役も治療役もアイテムもなしで行くと、失敗する。プレイヤーに納得感がある。

## 11. 調整方針

### 11.1 すぐ直すべき点

小鬼の洞窟の見回りだけ、大成功が出やすすぎる。ただし、最初のチュートリアル討伐としては許容範囲。

対応案：成功判定はそのまま／大成功報酬を控えめにする／大成功には「推奨アイテムを1つ以上持っている」条件を追加する／あるいは小鬼の洞窟では大成功時も報酬差を小さくする

### 11.2 直さなくてよい点

ミナがいない霧の森は危ない／エルンがいない毒草調査は不安／アイテムで弱点を補える／救助ミッションはちゃんと怖い／街道配達は新人育成枠として安全

### 11.3 今後の候補

次のモックアップでは、以下の調整を入れてよい。

ミッション要求値は3人合計前提／救助系は要求値を高めにする／低リスク依頼は安全にする／大成功は条件を少し厳しくする／失敗より部分成功が出やすいようにする

## 12. MVP向け最終仮方針

現時点では、判定式はこの方向で進めてよい。

採用する考え方：3人パーティ合計で判定する／ミッション要求値も、3人合計前提にする／アイテムで弱点補完できる／部分成功を多めに出す／救助は適正編成でも緊張感を残す／低リスク依頼はちゃんと安全弁にする
