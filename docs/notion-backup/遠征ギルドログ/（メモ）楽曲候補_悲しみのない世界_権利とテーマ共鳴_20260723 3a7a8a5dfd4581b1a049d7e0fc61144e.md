# 権利関係の調査結果

## 良い知らせ

- **zelone records は坂本慎太郎が2011年に自ら立ち上げた自主レーベル**（ゆらゆら帝国解散後）。メジャーの巨大な権利処理機構を相手にしなくてよい。窓口が小さく、話が通る可能性はゼロではない。

## 障害

1. **リミックスなので権利者が多い。** 原曲＝坂本慎太郎、参加＝Fuko Nakamura、リミキサー＝石原洋、原盤権＝zelone。**クリアすべき相手が複数**。オリジナル版より確実に面倒。
2. **国際的なアーティスト。** USツアーを重ね、US/EU/UKでもフィジカルリリースあり。**同人作家価格では絶対にない**。
3. **JASRAC/NexTone管理か要確認。** JASRACのJ-WID（作品データベース）で検索。管理曲なら著作権はJASRAC経由で処理できるが、**原盤権（音源そのもの）はzelone側と別途交渉**。

## 動くなら

- zelone records 公式サイトの問い合わせ先に、個人開発のゲームで使いたい旨を正直に書いて聞く。**タダなので損はない**（返事が来ない可能性も高い）。

## 実務上の落とし穴（ライセンス曲全般）

- **実況・配信で音楽著作権クレームが飛ぶ。** プレイ動画がYouTubeで自動検知されブロックや収益化剥奪になる。**実況が回らなくなるのは、インディーにとって宣伝経路を1本失うのと同じ**。「配信者モード」（ライセンス曲だけミュート）の実装コストもかかる。
- **クロスプラットフォーム配信の野心と衝突する。** コンソールに出す場合、プラットフォーマーが権利クリアの証明を求める。口約束では通らず、書面が要る。

# ★なぜこの曲なのか（テーマの共鳴）

## タイトルがゲームの主題そのもの

**「悲しみのない世界」＝悲しみが発生しない世界＝喪失が感じられない世界。**

→ これはまさに**アンチミームが作る世界**。誰も覚えていないから、誰も悲しまない。消えたことに気づけないから、悲しみが発生しない。

→ コアコンセプト5章の三項対立（記録できる死 / 記録できない消失 / 失い続ける側）と直接繋がる。

## 作風がトーンと一致する

坂本慎太郎の作風：**淡々として、乾いていて、日常の中に薄気味悪さが同居している**。

→ 「記録係が報告書を淡々と読む」という本作のトーンと驚くほど近い。

# ライセンスが無理だった場合に抽出すべきもの（作曲依頼の仕様書に使える）

- **感情を込めない歌い方**（距離のある語り。記録係の視点と同じ）
- **隙間の多い編成**（音を詰めない）
- **明るいのにどこか不穏**という同居

# 派生アイデア

- **「悲しみのない世界」という言葉自体を、ゲーム内で回収する**方向（アンチミームが作る状態を表す言葉として）。楽曲の使用可否とは無関係に検討できる。
