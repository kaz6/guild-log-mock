# 依頼A：狂った科学者の手記（介値タイトル）

## 状況

とある廃屋で、人の動きがだんだん遅くなっていき、その場で止まってしまうという怪事件が発生している。

## 無策で挻むと

- 無策で挑むと、冒険者のうち60人が捕まって動けなくなる
- その時点で任務失敗。他の3名は撤退判断をする（戦闘の撤退判断フェーズを流用できそう）
- 報告書にヒントが描かれる。廃屋にあった「手記」を入手する

## 手記の内容（テーマ）

自分の主観と相手の主観の差に囷られた研究者の記録。

- 自分の頭で考えて発話して相手に届くまでの時間差
- 自分の頭が腕を動かそうとして電気信号を発し、腕が実際に動くまでの時間差

これを研究し続け、狂ってしまった研究者がこの怪事件の原因。原因（研究者）に近づこうとすると、誰もが時間の流れを遅く感じて動けなくなってしまう。

## ロスト仕様

- この依頼ではロストはしない。解決すれば必ず戻ってくる
- ただし送り出せば送り出すほど、そこに固定（拘束）される冒険者が増えていく
- 未決：何人まで拘束されうるか、全員拘束された場合どうなるか（今回は未設計のまま残す）

# 連鎖の仕組み

1. 手記には、研究者の実家（別の地域へ引っ越した先）を示唆する手がかりが読み取れる
2. 別の地域向けの既存（または新規）依頼に、依頼Aを体験した同一メンバーを一人でも連れて行くと、ヒントを持ち帰ってくる
3. そのヒントから、研究者の引っ越し先が判明する
4. 引っ越し先の地域向け依頼（新規発生、または既存依頼）に、やはり同一メンバーを連れて行くと、アイテム（例：古びた懷中時計）を入手する
5. その懷中時計を依頼Aに持って行くと、事件が解決する

（懷中時計というアイテムは、手記のテーマ（主観間の時間差・時間の遅れ）と直接共鳴する。）

# このアイデアの良さ（レビューメモ）

- ロストなしでも「拘束される」という形で恐怖と代償を出せている（理不尽ロスト回避方針と整合的）
- 冒険者が拘束される＝他の依頼に使えなくなる＝自然なリソース圧が生まれる
- 「同じ冒険者を連れて行くと連絡がつながる」は、チェーン管理の新システムを作らずに済む軽量な実装ができそう
- 主観の時間差というテーマと、懷中時計というアイテムが見事に共鳴している
- 不穏な存在の示唆・発見・観察というゲームの第2層にも合致する

# 未決・今後詰める点

- 拘束人数の上限・全員拘束時の扱い
- 手記が入手するも、地域ヒントが読み取れない（失敗）パターンの有無
- 連れて行く先の依頼が新規か既存かで実装コストが変わる（既存依頼流用の方が軽い）
- 拘束中の冒険者は名簿上どう見えるか（選択不可な状態表示が必要）
