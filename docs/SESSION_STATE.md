### 【論点1】回復時間の具体値

- A（推奨）：**固定値**。無傷 0 ／ 軽症 **実5分**（ゲーム内2時間）／ 重症 **実1時間**（ゲーム内1日）
- B：**直前の依頼の所要時間に比例**。軽症 ×0.2 ／ 重症 ×1.0（隊商護衛なら重症3時間）

トレードオフ — A: 説明が1行で済み、軽症がほぼ即＝「連続で出したい」の受け皿になる／欠点：近場の1分依頼で重症になると回復1時間は割高に見える。B: 距離＝リスクと連動して自然／欠点：**同じ深手でも依頼で回復が変わる**理由を説明しにくく、遠方依頼を避ける動機になる

### 【論点2】拒否の境界

- A（推奨）：**stage と別軸。個人の帰還時HP率で切る**。既存の状態語の閾値をそのまま流用（70%超＝健在／35〜70%＝軽症／35%以下＝重症）
- B：**stage をそのまま使う**（軽→軽症、中→中等症、重→重症）

トレードオフ — A: 実測と一致し、新しい概念が増えない（状態語は既に実装・文書済み）。拒否が出るのは**個人の14.5%**＝4人編成で平均0.6人。連続運用を壊さない／欠点：報告書の結末（stage）と名簿の状態が一致しないので、その説明が要る。B: 結末と状態が一字一句そろう／欠点：**stage重は撤退でHPが高い**ので「撤退したら全員重症」になる。stage中67%が全員中等症になり、実質全員が同じ状態になる

### 【論点3】拒否の見せ方

- A（推奨）：**選択はできる。遠征開始で本人が断る**（受付嬢経由の1行）
