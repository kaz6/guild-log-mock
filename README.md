# 遠征ギルドログ HTML Mock v0.1.1

ブラウザだけで動く静的HTML Mockです。外部ライブラリは使っていません。

## 今回の改修テーマ

**ログ変化強化版**です。v0.1のUIを大きく変えず、同じ依頼でも毎回違う報告書になるようにしました。

## v0.1.1で追加・強化したこと

- 依頼ごとのイベントプール
- 天候ランダム
- 道中イベントランダム
- 冒険者の性格リアクション
- 冒険者の前職リアクション
- 支給品リアクション
- 成功 / 部分成功 / 持ち帰り / 再配達 / 観察優先などの結果差分
- 冒険者ごとの履歴追記
- 画面には表示しない裏パラメータ
  - totalExpeditions
  - totalReportsOpened
  - attachmentScore
  - recordDensity
  - anomalyPressure

## あえて入れていないこと

終盤向けの大きなテーマは、画面・観察記録・報告書本文には出していません。
最初はあくまで「通常のギルド業務」として、冒険者の人生と報告書を楽しめるかを検証します。

## ファイル構成

- `index.html`
- `style.css`
- `app.js`

## 使い方

1. `index.html` をブラウザで開く
2. 「依頼掲示板」から依頼を選ぶ
3. 冒険者と支給品を選ぶ
4. 「遠征開始」
5. ギルド画面で報告書の到着を待つ
6. 未開封報告書を開く
7. 必要なら冒険者名簿でメモを編集する

## おすすめの確認方法

同じ依頼を何度か繰り返してください。

- `届けられなかった手紙` + ミナ + 油紙の手紙入れ
- `森の薬草採集` + エルネ + 包帯 / 携帯鍋
- `古い道標の確認` + ミナ + 古地図 / 笛

同じ依頼でも、天候・道中イベント・支給品・性格・前職・結果が変わります。
