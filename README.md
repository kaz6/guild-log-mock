# 遠征ギルドログ HTML Mock v0.1.2

ブラウザだけで動く静的HTML Mockです。外部ライブラリは使っていません。

## 今回の改修テーマ

**生活依頼追加版**です。戦闘・敵遭遇のない「生活依頼」カテゴリを正式に実装しました。

## v0.1.2で追加・強化したこと

- 生活依頼2件を追加
  - 「結婚式の裏方」（会場設営・厨房・酒樽運搬・招待客案内・迷子対応・夜間見回り・飾り紐受け渡し）
  - 「廃屋の片付け」（家具撤去・床板確認・古い手紙整理・生活用品確認・茶器梱包・近所の聞き取り）
  - 廃屋のログは「誰かが確かに暮らしていたが、今では誰だったか分からない」余韻の文面
- 生活依頼専用ログ生成フロー（`lifeQuestEventPools`）
  - 天候・道中戦闘ではなく、作業報告・住民とのやり取り・冒険者の個性ログを生成
  - 作業結果：成功 / 感謝 / 小さな失敗 / 整理完了 / 一部保留
  - 冒険者の性格（慎重・豪胆・世話焼き）と前職（郵便配達人・宿場の用心棒・村の調合係）が作業ログに反映
  - 依頼書カードの「危険度」表示を生活依頼では「作業負荷」に変更
- 観察記録の更新箇所ハイライト
  - 報告書を開封した際に観察記録が更新されると、新しく追加された行が薄くハイライト表示される
  - ハイライトは次の観察記録更新まで保持（更新時に旧ハイライトは消えて新しい箇所のみ表示）
  - `state.lastObservationUpdate` に記録。`localStorage` に保存される
- `subtle-danger` / `new-observation-highlight` CSSクラスを追加
- パーティ人数に応じたログ整合性修正
  - `party.length === 1` の場合は「一行は」「仲間の声」などの複数人前提ログを使わず、単独行ログを生成
  - `generateWeatherLog`：ソロ用テキスト一式を追加
  - `roadEventText`：倒木・道標の傾き・壊れた橋・封蝋の確認・犬の遠吠え・湿った足跡のソロ対応
  - `personalEventText`：「仲間の顔色」エントリをソロ時にスキップ
- 冒険者ごとの支給品割り当て（最小実装）
  - 遠征準備画面で各冒険者に支給品を1つずつ割り当てられるUIに変更
  - 同じ支給品は1人のみ所持（重複不可）
  - `expedition.adventurerItemIds` で保存。報告書に「ミナ：観察記録票 / ガッド：包帯」形式で表示
  - 支給品ログに所持者名が入るようになった（例：「ミナが持っていた古地図を広げ…」）
  - 本格戦闘ログ・「誰が誰に使ったか」のシステムはまだ未実装
- 観察記録票（支給品）を追加
  - 「観察記録票」を持たせて observationTarget が設定された依頼に出ると、報告書に冒険者ごとの観察メモが追加される
  - 冒険者ごとに `stats.memory`（1〜5）を追加。記憶力が高いほど詳細なメモが記録される
  - 性格・職業・前職ごとに着目点が違うメモが生成される（慎重→距離/危険度、豪胆→手応え/撃退感、世話焼き→仲間への影響/対策）
  - 現在の対応対象：森喰い兎（`quest_herb`）
  - いきもの図鑑の自由編集UI、王立魔法図書館への納品、終盤要素はまだ未実装
- **観察記録票なしでは観察記録を自動更新しない**
  - `observationTarget` がある依頼でも、観察記録票を誰も持っていない場合は観察記録本体を更新しない
  - 通常の遭遇ログはそのまま報告書に出る
  - 観察記録票ありの場合のみ、冒険者ごとの一次観察メモ＋観察記録ハイライトが機能する
  - 観察記録票セクションに記録を書けるのは**所持者のみ**。所持していない冒険者のメモは出ない
- **いきもの図鑑（プレイヤー編集）を追加**
  - ナビに「いきもの図鑑」タブを追加
  - 観察記録票を使った遠征の報告書詳細に「図鑑を編集」ボタンを追加
  - ボタンを押すと**右ドロワー形式の図鑑エディタ**が開き、観察記録票の内容を参考に手動転記できる
  - 背景オーバーレイが薄く、背後の報告書本文が少し透けて見える
  - 編集項目：対象名 / 分類 / 遭遇地域 / 外見・特徴 / 行動 / 危険性 / 有効だった対処 / 効かなかった対処 / 観察メモ / 次に確認したいこと
  - 保存は `localStorage` に永続化。プレイヤーが書いた内容は自動上書きされない
  - いきもの図鑑ページで全記録を一覧・再編集できる
- **アイテムログの主語を所持者優先に改善**
  - 支給品ログの主語は原則として「そのアイテムを持っている冒険者」に統一
  - 得意な冒険者が別にいる場合は補助・助言役として自然に登場（例：ガッドが鍋を持ち、エルネが火加減を口出し）
  - 所持者と得意な冒険者が同一の場合はそのまま使用
- **報告書から古い「観察記録更新」欄を削除**
  - 報告書詳細の下段にあった自動更新テキスト欄を削除
  - 役割整理：「観察記録票セクション」= 冒険者の一次メモ、「いきもの図鑑」= プレイヤー編集の完成形、「報告メモ」= 断片情報の素材置き場
- **「観察記録」を「報告メモ」に名称変更**
  - ナビボタン・画面タイトル・ボタン文言を「観察記録」→「報告メモ」に変更
  - いきもの図鑑とは別物として明確に区別
  - 報告メモはプレイヤーが図鑑に転記するための素材置き場
- **冒険者1人につき支給品を2個まで所持可能に拡張**
  - 遠征準備画面で、各冒険者にスロット1・スロット2の2枠を表示
  - 同じ冒険者が同じ支給品を2スロット両方に持つことは不可
  - 報告書には「ミナ：観察記録票・古地図 / ガッド：包帯」のように2個分まで表示
  - `adventurerItemIds` の形式を `{ advId: [itemId1, itemId2] }` の配列形式に変更
  - 旧形式（文字列）のLocalStorageデータは自動的に配列に正規化

## あえて入れていないこと

終盤向けの大きなテーマは、画面・観察記録・報告書本文には出していません。
最初はあくまで「通常のギルド業務」として、冒険者の人生と報告書を楽しめるかを検証します。

## 使い方

1. `index.html` をブラウザで開く
2. 「依頼掲示板」から依頼を選ぶ
3. 冒険者と支給品を選ぶ
4. 「遠征開始」
5. ギルド画面で報告書の到着を待つ
6. 未開封報告書を開く
7. 必要なら冒険者名簿でメモを編集する

## おすすめの確認方法

同じ依頼を何度か繰り返してください。

- `届けられなかった手紙` + ミナ + 油紙の手紙入れ
- `森の薬草採集` + エルネ + 包帯 / 携帯鍋
- `古い道標の確認` + ミナ + 古地図 / 笛
- `結婚式の裏方` + エルネ（世話焼き）+ ガッド（豪胆）
- `廃屋の片付け` + ミナ（慎重）+ ガッド（豪胆）
- `森の薬草採集` + ミナ：観察記録票 → 報告書から「図鑑を編集」で転記
- `森の薬草採集` + ミナ：観察記録票・古地図 ＋ ガッド：包帯・笛（2スロット確認）

観察記録票なしで遠征しても、報告メモ（いきもの図鑑の元データ）は更新されません。
観察記録票を所持した冒険者だけが観察記録票セクションにメモを残し、プレイヤーが自分でいきもの図鑑を育てます。
